## 重建知识边界与作者的思考路径（重要）

### 这篇论文诞生前的知识边界

2023 年 HPRC（Human Pangenome Reference Consortium）发布人类泛基因组参考（Liao et al., Nature 2023，本文引文 [28]）之后，泛基因组图从研究原型变成了默认基础设施：minigraph、Minigraph-Cactus、PGGB 的图被大量下游工具直接消费。但建图仍然昂贵，路线分成两支，各有各的墙。

第一支是参考嵌入族：把 VCF 里的已知变异嵌进线性参考（vg construct 一类做法）。这条路的成本不在建图，而在**变异必须先被叫出来**：每个新样本要先比对到线性参考、做变异调用和基因分型，VCF 才嵌得进去。giraffe+DeepVariant [28,32] 是这条路线目前的标杆，但它只在读段比对阶段用图，基因分型之前把图比对**射回（surject）线性参考**，所以参考偏置只是被推迟了一步，没有被消除。这条路线在重复区、复杂 SV 区本来就会失败，参考嵌入又把这些失败原样固化进图。

第二支是组装族：minigraph [27]、Minigraph-Cactus [20]、PGGB [16]、基于多序列比对的 Pandora/PanPA/Pangeblocks [10,11,3]。它们都要求**高质量、分相的从头组装**。组装本身昂贵：Verkko 这类工具要多种测序技术和高覆盖；10× 的低覆盖长读会让组装在着丝粒、端粒、节段重复处断掉（本文 4.4 节实测：hifiasm 在 10× 下漏掉 chr20 上 0.16% 的区域）。增量场景更麻烦：Minigraph-Cactus 要加入一个新个体，得把全部 n+1 个基因组重新跑一遍建图。

两堵墙背后是同一个被所有人默认的假设：**要往图里加东西，必须先知道加的是什么**。要么通过组装知道序列，要么通过变异调用知道变异，图只是变体集合的容器。本文推翻的正是这个假设。

### 前人真正撞墙的地方

具体场景：你有一张 n 个个体的泛基因组图，新测了一个 10× HiFi 的样本，想把这个人加进去。

组装路线在低覆盖下失明：hifiasm 组装出的 contig 覆盖不到 chr20 上 35 个区域（0.16%，本文 4.4 节），这些区域恰好是着丝粒、端粒和低覆盖区，正是泛基因组最该覆盖的地方；然后 Minigraph-Cactus 还要为这个新个体整图重建。你花最多的钱，在最该有图的地方没有图。

参考路线可以工作，但代价结构不对：每个样本都要全基因组比对加 DeepVariant 基因分型；重复区的比对伪影（winnowmap2 引文 [21] 承认的长期问题）直接变成假变异；参考上没有的序列（novel insertion、复杂 SV）本来就调不出来。而且这条路在概念上就堵死了：它只能往图里放**参考坐标系内能叫出来的变异**。

一个更近的工作 [34]（Schloissnig et al. 2024）确实做了图增广：用图比对调出的 SV 增广图。但它仍然依赖全读段图比对和变异调用，本质是参考路线的图版本，没有绕开**先调用变异**这一步。

这三条路的共同失败不是参数问题，是结构性假设问题：图更新被绑定在**变体枚举**这个中间表示上。突破点就是去掉这个中间表示。

### 作者的底气从哪里来

Denti 是第一作者，这套方法论的每一步都在他自己的作品序列里：

1. specific string 原语是这组人发明的：Khorsand et al. 2021 [22] 给出算法和应用，Béal & Crochemore 2023 [7] 给出理论形式化，Bonizzoni 是理论作者之一。
2. SVDSS（Denti et al., Nature Methods 2023 [13]）已经证明：用 FMD-index 对**线性参考**算 specific string、聚簇、局部一致化，能在真实 HiFi 长读上发现难调区域的 SV。本文等于把 SVDSS 的靶子从线性参考换成泛基因组图，把输出从变异调用换成图编辑。这是**工具有、问题在、就差把两者接上**的位置，不是从零赌一个 idea。
3. 规模可行性是 2024 年才成立的事：Li 的 ropebwt3（arXiv 2024 [26]）把 BWT 构建推到 terabase 级，整个泛基因组的单倍型集合才建得起 FMD-index。没有它，第一步就做不了。
4. 其余部件全是现成的轮子：abpoa（部分序比对）、ksw2（全局比对）、vg augment（图编辑）。工程风险集中在锚定和聚类两个启发式上，而这可以先做可行性实验检验。4.1 节的锚点覆盖实验放在最前面，就是这个逻辑：先把地基验掉，再谈整条管线。

还有一个几乎无法反驳的数据观察支撑整个方案（Method §3 开头）：一条读段只要支持某个与图不同的差异（真变异或测序错误），它就包含描述这个差异的子串；支持同一变异的读段包含**相似**的子串。相似而不相等，是因为测序错误、邻近变异和倍性。所以**读段里图外的子串**在原理上足以支撑局部组装。这不是赌注，是字符串匹配的直接推论。

### 措辞强弱地图

措辞的强弱分布就是作者对自己各部分把握程度的地图：

- 最强声称：摘要里的 **first assembly-free and mapping-free approach**。定义上成立，此前确实没有从读段直接增广图的方法。
- 次强声称：摘要的 **demonstrate the effectiveness**、4.3 节标题 **Graph augmentation is precise**。靠图 3、图 4 支撑，但精度指标是间接的（见第 4 节的审读）。
- 明显放软的地方：**we suspect** that the presence of complex subgraphs may affect minigraph alignments（4.2）、**we believe** that these results may be marginally biased towards the MGC graphs（4.4）、**most of these are actually sequencing errors**（4.3）。作者在三个最容易被审稿人攻击的位置（比对器偏置、对比公平性、假阳性来源）主动承认不确定性。
- 附录大篇幅的迹象：运行时间和内存（Supp Section A）、GraphAligner 复现（Supp Section B）、只统计完整比对的子分析（Supp Fig B）、组装质量 quast 表（Supp Table B）。运行时间与替代比对器被放附录，通常意味着这两块是审稿人会打、且结论不太漂亮的地方。本次提供的材料不含附录文本，这些数字无法核实。

### 方法是被怎么逼出来的：从最朴素的尝试到最终形态

1. **最朴素的想法**：把新样本读段全量比对到图上（GraphAligner 之类），比对差异即增广内容。问题：全量图比对贵；重复区比对伪影多；更本质的是，这一步等价于**先调用变异**，走回了参考路线的老路。
2. **换信息源**：不比对，用 FMD-index 对图的单倍型序列集合做 specific string 检测，直接抽出读段里图外的最小差异窗口。新问题立刻出现：specific string **定义上就不在图里**，抽出来了却不知道它属于图上哪个位置。
3. **解决定位**：specific string 的两侧必然是图内序列（否则它会更长），用两侧的 k-mer 去图里找位置。朴素做法是找一对在单倍型路径上顺序正确的 k-mer，然后搜它们之间的路径。路径搜索太贵，于是收缩成启发式：只保留位置可唯一定义的 k-mer（单个顶点标签内的唯一 k-mer）且频率够低的 k-mer（≤|W| 次出现），做成 sketch；锚定时上下游各查 20 个候选，按拓扑序差最小选一对。定位变成 O(1) 查表。
4. **解决噪声**：每条读段各带测序错误，specific string 被错误撑大。读段先过 hifiasm 纠错，再要求每个簇至少 s=2 条读段支持，簇内用 POA 取共识，把残留错误投票掉。
5. **解决倍性**：一个簇里可能混着两个单倍型（杂合位点、多等位变异）。先按 specific string 的长度比 0.97 分裂（不同长度的等位基因分开），再让 abpoa 输出至多两个共识（min_freq=0.25），二倍体先验直接编码进参数。
6. **从共识到图编辑**：共识是字符串，图是图。让共识对经过两个锚点顶点的单倍型路径做全局比对（ksw2），把 CIGAR 和差异串直接喂给 vg augment，后者把差异写成顶点分裂、新顶点和新边。到这一步，变异才第一次被**叫**出来。全文唯一一次真正的碱基级比对发生在这里，而且只发生在有差异的位点。

注意第 3、4 步背后的哲学：**位置近似、内容精确**。锚定和聚类都是故意的近似，因为后面有簇级精修兜底。这是一个可迁移的工程原则：昂贵的精确计算不花在全局，花在少数被便宜的近似筛出来的候选上。

### 承重结构与装饰

承重的只有三个部件：specific string 表示（把差异压缩成最小窗口）、锚点 sketch（把图外字符串放回图上）、簇级 POA 一致化（把噪声读段变成单倍型序列）。三者缺一个，管线就塌。

装饰和工程参数：0.97 长度比、min_freq=0.25、h=2、20 个候选锚点、s=2。这些在论文里没有消融支撑（见 4.3），改值多半只会小幅移动精度和召回的平衡。vg augment 是拿来主义，但选得聪明：它把**差异写成图编辑**这个最容易出 bug 的步骤外包给了测试过的工具。

### 论文讲的故事与可能的真实过程（推断）

论文的叙述顺序是：sketch 定义 → specific string → 锚定 → 聚类 → 簇分析 → 增广。这几乎肯定是教学顺序，不是发现顺序。更可能的真实路径（推断，依据是作者的工作序列和 v0.1 代码）：specific string 在 SVDSS 里已经成熟，真正的难点是**怎么放回图上**，锚点 sketch 才是本文的核心增量；聚类和 POA 是 SVDSS 经验的平移。代码与论文的出入支持这个判断：v0.1 代码里聚类按**完全相同的锚点 k-mer 对**分组，论文描述的是拓扑序区间重叠的扫描线；论文的 0.97 长度分裂在代码里找不到，改由 abpoa 的双共识参数承担；代码默认 k=31，论文实验用 k=27。论文描述是理想化版本，代码是修修补补后的现实版本。复现时按代码为准，理解机制时按论文为准。

### 四个核心问题

#### Problem

给一张**无环变异图** G=(V,E,W)（GBZ 格式，含 |W| 条单倍型路径）和一个不在图中的新个体的**未组装长读样本**，在**不组装、不全量比对、不调用变异、不重建整图**的前提下，把新个体单倍型里图外的序列内容（SNP、短 indel、以及支持它们的单倍型片段）以新顶点和新边的形式并入 G，使新个体的读段在增广图上的比对质量接近**早知道这个个体**的图（FULL）。验收指标是读段比对改善和新增顶点的支持度。论文没有用变体级金标准评分，这是它最大的评测缺口。

#### Motivation

泛基因组图的价值随覆盖的个体数增长，建图成本却是普及的最大障碍：组装路线要高质量分相组装加整图重建，参考路线要逐样本全基因组比对和基因分型，两者在新样本接入时都重复付费。读段直接增广把接入成本降到索引加局部比对，低覆盖（10×）样本也能进图，并且天然绕开参考偏置和组装盲区。本文 4.4 的案例就是组装漏掉、增广补上的区域。对临床队列、大规模种群测序、病原监测这类样本持续流入的场景，增量更新是唯一可持续的路线。

#### State of Research / Gap

在这项工作之前：图可以从 VCF 嵌入（vg construct）、从多序列比对（Pandora/PanPA/Pangeblocks）、从全对全比对（PGGB）、或从逐基因组序列-图比对（minigraph → Minigraph-Cactus）构建；specific string 可以针对线性参考高效计算（FMD-index [22]），SVDSS 用它调 SV；[34] 用图比对调出的 SV 增广图。但**没有任何方法从读段直接增广图**。为什么之前做不了：(a) 索引缺口：对整张泛基因组的单倍型集合建 FMD-index 直到 ropebwt3 才可行；(b) 机制缺口：图外子串没有定位手段，锚点 sketch 这个机制此前不存在；(c) 数据缺口：免组装路线要求读段足够准，HiFi 和成熟纠错器近年才普及；(d) 概念缺口：**图更新必须经过变体枚举**这个默认假设没被质疑过。作者恰好占齐 (a)(b)(c)：specific string 原语是他们的，ropebwt3 是现成的，SVDSS 证明了可行性。这是**工具有、缺口在**的组合。

#### Contribution

核心洞见一句话：**读段与泛基因组的全部差异可以用 specific string 精确捕获，其位置可以由两侧 k-mer 锚点近似决定；于是昂贵的精确比对只花在真正有差异的少数位点（簇级 POA 微组装加局部路径全局比对），图编辑交给 vg augment。** 可迁移的解决原则：把**先推断出变异、再写入图**的顺序倒过来，改成**先把读段中的差异片段近似放到图上，让变异在最后一步对齐中自己显现**；图更新从推断问题变成表示问题。

具体贡献：

1. **新问题定义**：assembly-free、mapping-free、不重建的增量图增广任务，以及**增广到读段比对与 FULL 图一致**这个可操作的验收标准。
2. **solid anchor 图 sketch**：单个顶点内唯一加 ≤|W| 次出现的 k-mer 过滤，首次给图外子串提供了可查表的定位机制。
3. **完整管线 PALSS**：锚定、扫描线聚类、长度比分裂、abpoa 双共识、ksw2 路径对齐、vg augment 嵌入、support≥s 过滤，全部开源可复现。
4. **证据**：96.6% 的基因组（chr1/11/20）锚点可达，99.4% 的真实 ONT 读段可锚定；10× 模拟 HiFi 增广后读段比对与 FULL 图的 ΔMatches 中位数为 0；99% 的新顶点被比对支持；在 10 个 hifiasm 组装盲区正确增广了 Minigraph-Cactus 漏掉的变异。

## 1. Abstract｜全篇压缩

### 1.1 Task

领域定位：泛基因组学里的图构建问题。任务：给一张既有的泛基因组变异图和一个新个体的长读样本，把新个体特有的序列内容（SNP、短 indel、单倍型片段）写进图的拓扑（新顶点、新边），且全程不组装、不全量比对读段。关键科学问题：不经过组装或变异调用这两个传统中间表示，图外序列如何被发现、定位、一致化并写成图编辑。

### 1.2 Technical challenge for previous methods

既有路线全部绑定中间表示：组装族（Minigraph-Cactus、PGGB）要求高质量分相组装加整图重建，参考族（vg construct、giraffe+DeepVariant）要求逐样本比对和基因分型，且基因分型前把图比对射回线性参考，参考偏置未除。真正要推进的增量是：在去掉组装和比对之后，specific string 这类图外子串**定义上不在图中**，无法直接定位；且单条读段的差异窗口带测序错误、跨单倍型混杂，无法直接写成图编辑。

### 1.3 Key insight / motivation

读段与泛基因组的全部差异可以用 specific string 精确捕获，其位置可以由两侧 k-mer 锚点近似决定；于是昂贵的精确比对只花在真正有差异的少数位点。图更新从推断问题变成表示问题：先把差异片段近似放到图上，让变异在最后一步对齐中自己显现。

### 1.4 Technical contributions

- **solid anchor 图 sketch：** 只保留单个顶点标签内唯一且在图内出现 ≤|W| 次的 k-mer，连同 (顶点, 偏移) 存成 sketch。价值：首次给定义上不在图中的 specific string 提供了 O(1) 可查表的定位机制，免去路径搜索。
- **specific string 计算与锚定：** 对图的单倍型集合建 FMD-index（ropebwt3），用 ping-pong 双向扩展算法抽出读段中所有图外最小窗口，用上下游各 20 个候选锚点按拓扑序差选一对定位。价值：差异检测是精确的字符串运算而非启发式比对，免去比对伪影。
- **簇级局部微组装与图增广：** 锚点区间扫描线聚类、长度比 0.97 分裂、abpoa 部分序比对取至多两个共识（min_freq=0.25）、ksw2 对局部单倍型路径全局比对、vg augment 写成图编辑、support≥s 过滤。价值：噪声投票掉、二倍体先验内建、精确计算只花在有差异的位点。
- **工具与证据：** PALSS 开源；96.6% 基因组锚点可达；增广图读段比对与 FULL 图一致（ΔMatches 中位数 0）；99% 新顶点被支持；补上 Minigraph-Cactus 在组装盲区漏掉的变异。

### 1.5 Experiment

数据：HPRC 变异集对 T2T-CHM13 用 vg 建的图，n ∈ {1,2,4,8,16,32} 个随机个体，主实验在 chr20；新个体用 pbsim3 模拟 HiFi 读段（每单倍型 5×，共 10×），hifiasm 纠错后跑 PALSS（k=27）。指标：minigraph 把读段比对到 FULL（n+1 个体的图）、10UT（n 个体的图）、10UT-AUG（增广图）、MGC（Minigraph-Cactus 图）的编辑距离和 ΔMatches；新顶点被比对支持的比例。核心结果：10UT-AUG 与 FULL 的 ΔMatches 中位数对所有 n 都是 0；n=1 时 99%、n=4 时 95% 以上的新顶点被至少一条比对支持；FULL-AUG 对照（对已含个体的图增广）只加少量支撑为 1 的顶点，指向残留测序错误；在 15 个 hifiasm 组装漏掉的区域里正确增广了 10 个 MGC 漏掉的变异。结论适用范围：需纠错长读、无环图、带单倍型路径的变异图。

## 2. Introduction

### 2.1 Task and application

- 任务定义：输入是一张无环变异图 G=(V,E,W)（GBZ 格式，顶点标签为非空 DNA 串，W 是单倍型路径集合，图的构造来自 HPRC 变异集嵌入 T2T-CHM13）和一个不在图中的新个体的纠错长读样本；输出是增广图（GFA 格式），以新顶点和新边编码新个体单倍型里图外的序列内容。目标指标：新个体读段在增广图上的比对质量（编辑距离、匹配残基数）接近 FULL 图（直接用 n+1 个个体建的图），同时新增顶点几乎全部被读段比对支持（少假阳性）。
- 重要性：泛基因组图的价值随个体数增长，建图成本却是普及的最大障碍。单线性参考有结构性偏置（引文 [28,20]），泛基因组是方向，但把新样本接入图目前要么要求昂贵组装加整图重建，要么要求逐样本比对加基因分型。
- 应用：论文展示的应用是渐进式图构建（progressive augmentation）：一张既有图加一个新样本的低覆盖读段，图就多一个人的多样性；以及补组装盲区（4.4 案例）。

### 2.2 Technical challenges for previous methods｜本文真正要解决的问题

#### Technical challenge 1 — 建图路线被高质量组装卡死

**Previous method：** minigraph 逐基因组序列-图比对建图（只收 SV，有损），Minigraph-Cactus 在其上加 remap 补 SNP 和短 indel；PGGB 做全对全比对；Pandora/PanPA/Pangeblocks 做多序列比对。

**Failure cases / limitation：** 10× 低覆盖长读下 hifiasm 组装漏掉 chr20 上 35 个区域（0.16%，本文 4.4），这些区域集中在着丝粒、端粒和低覆盖区；Minigraph-Cactus 加入新个体必须整图重建；全对全或多序列比对随个体数超线性膨胀。

**Technical reason：** 组装是覆盖和测序技术敏感的全局计算，低覆盖时组装图断裂，断裂处的变异永远不会进入下游建图；整图重建把每个新样本的边际成本抬到与建图本身同级。组装被当作建图的必经中间表示，是结构性问题，不是参数问题。

**Research gap：** 需要一条不经过组装的建图/增广路径：直接从读段提取新个体与图的差异并写入图。本文 4.4 的案例表明这条路径能覆盖组装盲区。

#### Technical challenge 2 — 参考路线的偏置与成本

**Previous method：** giraffe+DeepVariant：图比对 + 射回线性参考 + DeepVariant 基因分型，再把 VCF 嵌入图（vg construct 一类）。[34] 用图比对调出的 SV 增广图，属于这条路的图版本。

**Failure cases / limitation：** 基因分型在射回线性参考后发生，参考偏置没有消除；重复区比对伪影（引文 [21,37]）会固化成假变异；参考上不存在的序列（novel insertion、复杂 SV）调不出来；每个新样本都要付全基因组比对加基因分型的成本。

**Technical reason：** 这条路的图更新被绑定在变异枚举上：图只能接收参考坐标系内能叫出来的变异。变异调用器的盲区就是图的盲区。

**Research gap：** 需要一条不比对、不调用变异的增广路径，让差异检测在字符串层面（specific string）而不是比对推断层面发生。

#### Technical challenge 3 — 图外子串的定位与一致化

**Previous method：** specific string 的检测算法（FMD-index ping-pong 搜索，[22,13]）只针对线性参考，给出的是读段中参考外的最小窗口，没有图上的坐标；SVDSS 的聚簇依赖读段间 Jaccard 相似度，输出是变异调用不是图编辑。

**Failure cases / limitation：** specific string 定义上不在图中，无法直接定位；单条读段的差异窗口带测序错误、跨单倍型混杂（杂合、多等位），直接写进图就是噪声。

**Technical reason：** 图外子串和图之间没有任何共享索引：图内索引（FMD）回答不了这个图外串属于哪里，图结构（顶点、路径）又不含读段内容。需要一个把两者连起来的机制。

**Research gap：** 本文要新增的机制：k-mer 锚点 sketch 提供定位，锚点区间聚类加 POA 一致化提供内容精化。这是本文相对 SVDSS 的真正增量。

### 2.3 Our pipeline：如何解决 challenge

#### 2.3.1 Key innovation / insight / contribution

一句话：差异检测用精确的字符串运算（specific string），位置放置用 k-mer 锚点近似，内容精化用簇级 POA 微组装，图编辑用 vg augment。昂贵的精确比对只发生在少数有差异的位点。

#### 2.4.2 Contribution 1 — solid anchor 图 sketch

**Problem addressed：** 挑战 3 的定位问题：specific string 不在图中，需要知道它属于图上哪里。

**Approach：** 定义 anchor 为只出现在单个顶点标签内的 k-mer；solid anchor 再加出现次数 ≤|W| 的过滤（每个单倍型至多一个拷贝）。sketch 存 (k-mer, 顶点, 偏移)。锚定 specific string 时，在上下游各查最多 20 个在读段内唯一的 k-mer，选拓扑序差最小且顺序正确的一对。

**Advantage/insight：** 定位变成 O(1) 查表，免去路径搜索；唯一性约束保证定位确定，≤|W| 约束过滤重复区歧义。验证：4.1 节锚点覆盖实验。

#### 2.4.3 Contribution 2 — 簇级 ploidy-aware 局部微组装

**Problem addressed：** 挑战 3 的一致化问题：同一变异的读段子串相似但不相等（测序错误、邻近变异、倍性），且簇里混着两个单倍型。

**Approach：** 锚点区间扫描线聚类；长度比 0.97 分裂不同长度等位基因；支持 ≥s=2 的簇用 abpoa 部分序比对取至多两个共识；共识对经过两锚点顶点的局部单倍型路径做 ksw2 全局比对，取最优；CIGAR 和差异串交给 vg augment 写成图编辑，新顶点新边再按支持 ≥s 过滤。

**Advantage/insight：** 二倍体先验（h=2、min_freq=0.25）内建；POA 把残留测序错误投票掉；精确比对只花在有差异的位点。验证：图 3、图 4。

#### 2.4.4 Contribution 3 — 从读段直接增广图的完整管线与工具

**Problem addressed：** 挑战 1、2 的整体问题：不组装、不比对、不重建地把新个体加进既有图。

**Approach：** 把贡献 1、2 串成 PALSS（github.com/ldenti/palss）：GBZ 图 + 纠错读段进，增广 GFA 出，中间只经过 FMD 索引、sketch 查询和局部比对。

**Advantage/insight：** 首次展示读段直接增广图这条路线在 10× 模拟 HiFi 上可行且与 FULL 图对齐质量一致，并在组装盲区补上 MGC 漏掉的变异（图 5 案例）。

### 2.5 Demos / applications

论文的直观案例是图 5：chr20:17563000-17563300 位点，图内个体 HG01361 在此无变异，新个体 HG01123 纯合携带 1bp 插入（A）和 C>T SNP。hifiasm 在 10× 下没组装出这个区域，Minigraph-Cactus 的图因此只有一条长顶点（与 10UT 相同），两个变异都丢了；PALSS 增广后的图多了 C>T 的气泡和一个 1bp 的新顶点 A。定量的完整对比见第 4 节 E4。

## 3. Method

### 3.1 Overview

#### 具体的任务

- 输入：无环变异图 G=(V,E,W)，GBZ 格式，含 |W| 条单倍型路径（图由 HPRC 变异集对 T2T-CHM13 用 vg 构造）；新个体的纠错长读（FASTA/FASTQ）。
- 输出：增广后的图（GFA 格式）：新顶点、新边编码新个体单倍型里图外的序列内容。
- 目标：新个体读段在增广图上比对质量接近 FULL 图；新顶点几乎全部被读段支持。

#### 方法总体流程

七个阶段（图 1）：(i) 从图的单倍型路径建 FMD-index，从图建 solid anchor sketch；(ii) 在每条读段上计算 specific string；(iii) 用两侧锚点把 specific string 钉到图上；(iv) 按锚点位置聚类；(v-vi) 每个簇做部分序比对取共识（二倍体位点取两个共识），共识对局部单倍型路径做全局比对；(vii) 碱基级比对交给 vg augment 写成图编辑。

### 3.2 Pipeline module 1 — 图 sketch（solid anchors）

**Motivation：** specific string 定义上就不在图内，FMD-index 只负责**检测差异**，回答不了**差异在图上哪里**。需要一组图内、且位置可唯一确定的 k-mer 当坐标钉。

**做法：** anchor 定义为只出现在单个顶点标签（长度 ≥ k）内的 k-mer。solid anchor 再要求它在全部单倍型里的出现次数 ≤ |W|。sketch 存每个 solid anchor 的 (k-mer, 顶点 v, 顶点内偏移 o)。构建时遍历每个顶点的标签取所有 k-mer，对每个 k-mer 数它在 |W| 条单倍型中的出现次数，满足两层条件的才入库。实现上是 canonical k-mer（k-mer 与其反向互补里字典序较小者），带方向位。

**为什么能 work：** 两层条件各防一种歧义。单顶点条件保证 k-mer 出现时，位置 (v, o) 是唯一定义的；跨边 k-mer 的位置要写成 (u, v, 两偏移)，且集合大一个量级，被排除。≤|W| 条件保证每个单倍型至多一个拷贝：一个 k-mer 若在所有 |W| 条单倍型里恰好各出现一次，总计 |W| 次，它在任何单倍型里的位置都被唯一锁定；出现 |W|+1 次就意味着至少一个单倍型里有旁系同源拷贝（节段重复的典型签名），定位会歧义。几何读法：solid anchor 是一个图钉，把读段钉在图上唯一的位置。它本质上是 mappability（唯一比对性）的 k-mer 版替身：免去比对、直接查表。

**Technical advantage：** 定位 O(1) 查表，免去**搜索两锚点之间的路径**这个昂贵步骤；对比 minimizer 类图索引（minigraph、PanKmer [27,5]），思路同源（k-mer 集合加频率过滤），但存储目标不同：这里存 (顶点, 偏移) 用于图坐标定位，不是 (基因组, 坐标)。

展开两点。k=27 是怎么来的：论文实验统一用 27，正文没有给选择依据，代码默认是 31，v0.1 实验配置里还有密度参数 d ∈ {0.33, 0.5, 0.75} 的扫描痕迹。合理猜测（推断）：27 在 32 位整数内方便打包 k-mer（27×2 bit = 54 bit，加方向位可塞进 64 bit），且对 3Gbp 的人类基因组足够特异。这不是承重参数，但没有消融。另一个被忽略的细节是 solid 条件的非等价性：≤|W| 是启发式阈值（论文原话 **heuristically-derived**），它把**每个单倍型至多一个拷贝**翻译成全局计数条件。这个翻译不是等价的：k-mer 可能在单个单倍型内出现两次、在另一个单倍型内不出现，总数仍 ≤|W|。论文对此没有讨论，实际影响未知。

### 3.3 Pipeline module 2 — specific string 计算与锚定

**Motivation：** 需要精确提取**读段中图外的最小差异窗口**。specific string 的定义（引文 [22,7]）：给定字符串集 R（图内单倍型）和 T（读段），specific string 是 T 中出现在某条读段里、不出现在任何 R 串里的最短子串，且它的所有真子串都在 R 中出现。它是**差异**在字符串层面的最小完整单位。

**做法：** 用 gbz_extract 把图的单倍型路径抽成字符串，ropebwt3 建 FMD-index。FMD-index 是 FM-index（BWT 压缩全文索引）的扩展：对字符串集合及其反向互补一起建索引，支持前向和后向双向扩展查询。specific string 用 ping-pong 算法（[22]，本文按 ropebwt3 API 重实现）：从读段右端开始，向后扩展直到区间为空，再从断点向前扩展直到区间为空，报出一个窗口，然后从窗口尾退一位继续，最后把重叠或相邻（d=0）的窗口合并成 superstring（论文把合并结果也简称为 specific string）。

**为什么能 work：** 关键性质：ping-pong 恰好把**每个包含变异的 k-mer 报出一次**，合并后每个孤立变异对应一条 2k−1 长的窗口，变异在窗口正中。用 k=4 的微型走查演示。设读段 P = TTACGAACGTT，位置 5 是变异碱基（图上是 T，读段是 A），图内恰好不含任何含变异的 4-mer，而所有短串都出现在图内（真实基因组上成立，几十 bp 的串到处都有）。第一轮：从右端向后扩展，区间依次代表 T、TT、GTT、CGTT、ACGTT、AACGTT，到 AACGTTT 区间变空，说明最长图内后缀是 AACGTT，断点 begin=5。从 5 向前扩展：A、AA、AAC 都在图内，AACG（含变异的 4-mer）变空，报出 [5,8]。下一轮从 7 开始向后：AC、AAC 在图内，GAAC 变空，断点 4，向前报出 [4,7]。同理报出 [3,6]、[2,5]。全部报完后从 4 向后，TTACG 全程在图内走到读段头，结束。四个窗口 [5,8][4,7][3,6][2,5] 重叠合并成 [2,8] = ACGAACG，长度 2k−1 = 7，变异 A 在正中（偏移 k−1 = 3）。算法时间线性于报出窗口的总长，这是 [22] 的理论保证。

**Technical advantage：** 差异检测是精确的字符串集合运算，不是比对推断：不产生比对伪影，不依赖比对器在重复区的表现。代价有两个。读段要先纠错（论文用 hifiasm 的纠错模式）：每个测序错误都等价于一个假变异，会撑大 specific string 数量和后续运行时间。论文声称纠错提升精度和速度，但没有给定量对比，v0.1 代码实验里也没有未纠错对照组。specific string 还只对**图外序列**敏感：新个体与图一致的等位基因不产生任何信号，杂合位点上只有 alt 单倍型贡献 specific string（3.7 会展开）。

锚定步骤。设 x = R[b, e] 是一条 specific string。查上游 k-mer R[i, i+k]（0 ≤ i ≤ b−k）和下游 k-mer R[j, j+k]（e ≤ j ≤ r−k）是否命中 sketch。命中后按启发式选一对：顶点拓扑序差最小且顺序正确；并列时选读段上离 specific string 最近的；上下游各只查 20 个候选（用户可调）；且只考虑在读段内唯一的 k-mer，防止新重复（如读段内的新复制拷贝）把锚点钉错位。选中的子串从上游锚点起点延伸到下游锚点终点，叫 anchored specific string。若无可用锚点对，该 specific string 被丢弃（论文没有明说，这是推断，代码路径一致）。

为什么要拓扑序：无环变异图的顶点可以线性编号，上下游关系就退化成编号大小比较，免去图遍历。为什么读段内唯一性重要：锚点唯一性是这个方案的地基，读段内出现两次的 k-mer 无法确定该用哪个拷贝。

### 3.4 Pipeline module 3 — 聚类

**Motivation：** 同一位点的 specific string 应该进同一个簇，不同位点分开。每个 anchored specific string 的位点可以用两锚点之间的子图表示，但子图相交判断贵。

**做法：** 用拓扑序区间 [v_a, v_b] 近似子图。扫描线算法：按上游锚点的（顶点序, 偏移）排序；第一条开一个簇，后续每条与当前簇比较，区间重叠就并入并维护最左最右锚点，否则开新簇。然后每个簇统一锚点：所有成员扩展到簇的最左最右锚点（读段上够得着就扩，够不着就过滤掉），强制簇内所有串起点终点一致。最后丢掉支持读段数 < s=2 的簇。

**为什么能 work：** 又是一个**位置近似、内容精确**的实例。作者承认区间近似可能把真子图不相交的串并进一个簇（拓扑序区间经过 superbubble 时包含不可达顶点），但论证了无害：后续精修只考虑经过两个锚点顶点的单倍型路径，多余顶点不参与增广。簇内强制统一锚点后，POA 的输入长度一致，比对结果干净。

**Technical advantage：** 聚类 O(S log S)（S 为 specific string 数），把**同变异读段聚合**从读段间相似度计算（SVDSS 的 Jaccard 路线，O(S²) 级别）降到一次排序。注意 v0.1 代码与论文描述不一致：代码按**完全相同的锚点 k-mer 对**分组，没有区间重叠逻辑。两种实现各有利弊：区间聚类能容忍不同读段选中相邻锚点，代码实现则在锚点选择不一致时会裂簇。复现实验时这是第一个要核对的地方。

### 3.5 Pipeline module 4 — 簇分析（共识生成与对齐）

**Motivation：** 一个簇里是多条带噪声的 anchored specific string，还可能混着两个单倍型（杂合、多等位）。要把簇总结成一条或两条单倍型共识序列，并对齐回图的局部区域。

**做法：** 三步。
第一步，按长度分裂处理多等位：两条 anchored specific string 长度比超过 0.97（默认）算同一单倍型，否则分裂；保留支持最多的 h=2 个子簇（二倍体先验）。
第二步，每个子簇用 abpoa 部分序比对（POA）取共识。POA 把序列渐进加入一个 DAG（先导图），全局比对后对 DAG 加权投票生成共识。参数 max_n_cons=2、min_freq=0.25：支持率 ≥25% 的第二个共识允许出现（杂合位点或等长双等位）；纯合位点自然只出一个共识。
第三步，共识对齐回图：提取经过两锚点顶点的所有单倍型路径（用 GBWT 的 r-index 快速定位），按诱导序列去重，用 ksw2 对每条路径做全局比对（asm10 类打分：match +1、mismatch −9、gap open 16、gap ext 2），保留最优。输出 GAF 记录（含 CIGAR 和 cs 差异串）。

**为什么能 work：** POA 的投票机制把残留测序错误平均掉：HiFi 残错 ~0.1%，10 条读段在同一位置同时错同一碱基的概率可以忽略。min_freq=0.25 和 h=2 把二倍体先验写进参数：一个位点至多两个等位基因。ksw2 只对齐到**局部**路径（两个锚点之间的子图），这是全文唯一一处传统碱基级比对，计算量集中在真正有差异的位点。

**Technical advantage：** 对比 SVDSS 的整读段 Jaccard 聚类加长窗口一致化，这里的输入已经是被锚点截短的窗口，长度一致、方向一致，POA 直接可用。代价：共识要逐条对齐多条路径，作者承认这是管线瓶颈（论文原话 **This is the main bottleneck of the approach**），并预告未来用对子图的动态规划替代（引 RecGraph [4]）。v0.1 代码与论文还有一个出入：代码先用 5-mer 计数的 Canberra 距离预选一条路径再 ksw2 对齐，论文写的是对齐所有路径取最优得分；代码还会丢弃两端带 clip 的共识，论文没提。

### 3.6 Pipeline module 5 — 增广（vg augment + 支持过滤）

**Motivation：** 共识与路径的碱基级差异要变成图的顶点分裂、新顶点和新边。自己写这个转换容易出 bug，vg augment 是现成的。

**做法：** 把上一阶段的 GAF 记录交给 vg augment（--include-paths --min-coverage 1），它把比对中的差异嵌入图：匹配区保留原顶点，插入区新建顶点，替换区把原顶点拆成气泡。然后 PALSS 自己再过滤：每个新顶点、新边必须被 ≥ s 条**不同读段**的 GAF 记录支持才保留（GAF 记录携带来源读段名，支持集合按读名去重）。

**为什么能 work：** 变异在这一步才第一次被**叫**出来：cs 串里的 `+A` 变成 1bp 顶点，`*CT` 变成气泡两边。前面所有阶段都不需要枚举变异。支持过滤针对残留测序错误：随机错误在错误纠正后很难在同一位置被两条读段支持，s=2 一刀切掉大部分。图 4 显示这一刀不干净：FULL-AUG 里剩下的假顶点几乎全是支持 1 条读段的。

**Technical advantage：** 图编辑外包给社区测试过的工具；支持过滤给新内容附带了证据计数，可以按需调严或调松。代价：vg augment 可能产生环，增广后的图不再保证无环，所以评价只能用容忍环的比对器（minigraph、GraphAligner），这也是论文 4.2 的说明。

### 3.7 完整实例走查

用一个缩小但结构真实的例子把整条管线走一遍，数据是示意构造，机制与图 5 的真实案例一一对应（图内个体 HG01361，新个体 HG01123 纯合携带 1bp 插入 A 和 C>T SNP）。

**设定。** k=9（论文用 27，为了纸上可算）；图是 n=1 的泛基因组，三条单倍型（T2T-CHM13 参考 + HG01361 两条）在该位点完全相同，所以图在该位点只有一条顶点 v111265，标签 S′（81bp）：

```
S′ = GATCCTAGGTACACGGATGCAGTTCGAACCGGTTAATCCGTATGCTAAGGTCCGAATTCGGCCTATAGCCTAGGCTAGTCA
```

新个体 HG01123 纯合：在第 21 位（0 起）后插入 A，第 50 位 C→T（图上是 C）。读段 R′（83bp，纠错后）：

```
R′ = GATCCTAGGTACACGGATGCAAGTTCGAACCGGTTAATCCGTATGCTAAGGTTCCGAATTCGGCCTATAGCCTAGGCTAGTCA
```

**步骤 1，specific string。** ping-pong 对 R′ 报出两簇重叠窗口，合并后得到两条 specific superstring：SS1 = R′[13..28] = CGGATGCAAGTTCGA（16bp，插入窗口；理想长度是 2k−1 = 17，这里因为插入的 A 与前一个 A 构成同聚物，R′[21..29] = AGTTCGAAC 恰好等于 S′[20..28]，窗口短了 1bp。同聚物处的插入正是长读数据里最难分的变异，窗口缩短是它的忠实反映）；SS2 = R′[43..59] = GCTAAGGTTCCGAATTC（17bp = 2k−1，SNP 窗口，变异的 T 在正中）。

**步骤 2，锚定。** SS1 上游候选（0 ≤ i ≤ 13−9）：R′[0..8] = GATCCTAGG@v:0、R′[1..9]@v:1、R′[2..10]@v:2、R′[3..11] = CCTAGGTAC@v:3（R′[4..12] 在玩具里查不到，真实基因组上会命中，这是玩具尺度造成的）；下游（j ≥ 28）：R′[28..36] = AACCGGTTA@v:27。所有候选都在同一顶点，拓扑序差为 0 并列，取离 specific string 最近的一对：anchored SS1 = R′[3..36] = CCTAGGTACACGGATGCAAGTTCGAACCGGTTA（34bp），锚点 (v:3, CCTAGGTAC) 和 (v:27, AACCGGTTA)。SS2 同理：上游 R′[34..42] = TAATCCGTA@v:33，下游 R′[67..75] = TAGCCTAGG@v:65，anchored SS2 = R′[34..75] = TAATCCGTAGCTAAGGTTCCGAATTCGGCCTAATAGCCTAGG（42bp）。

**步骤 3，聚类。** 区间 [3,27] 与 [33,65] 不重叠，两条进两个簇。每个簇收进 10 条 anchored specific string（5×/单倍型 × 2 单倍型）。若两个变异相距小于约 2k，它们的 k-mer 窗口会合并成一条 superstring，一个簇一次处理，这是真实数据里的常见情况。

**步骤 4，共识。** 簇 1：9 条串完全相同，1 条在第 31 位带一个残留纠错错误（G→A）。abpoa 投票恢复 G，共识 = CCTAGGTACACGGATGCAAGTTCGAACCGGTTAA（纯合位点，单共识）。簇 2：10 条全同，共识 = anchored SS2 本身。若换成另一个杂合位点，图上是 G，新个体一条单倍型带 T、另一条带 C，两条单倍型都不在图内，abpoa 会按 min_freq=0.25 输出两个共识，增广出双等位气泡。

**步骤 5，路径对齐。** 簇 1 的三条单倍型路径诱导同一序列，去重后对齐到 S′[3..35] = CCTAGGTACACGGATGCAGTTCGAACCGGTT（33bp）：CIGAR 18M1I15M，cs = :18+A:15。簇 2 对齐到 S′[33..74] = TAATCCGTAGCTAAGGTCCCGAATTCGGCCTATAGCCTAGG：CIGAR 17M1X24M，cs = :17*CT:24（路径上是 C，共识是 T）。

**步骤 6，增广。** vg augment 把簇 1 的插入写成：在 S′[21] 与 S′[22] 之间分裂 v111265，插入新的 1bp 顶点（标签 A）；把簇 2 的替换写成 S′[50] 处的气泡（主干 C，新支 T）。支持过滤：两个新顶点的支持读段数都是 10 ≥ 2，保留。增广后的图在该位点读作：S′[0..21] → [A] → S′[22..49] → 气泡{C|T} → S′[51..80]。

**步骤 7，验收。** 把 R′ 比对回增广图：编辑距离 NM = 0。比对回 10UT（原始单顶点）：1 个插入加 1 个错配，NM = 2。

**同一场景在基线上。** 组装路线（Minigraph-Cactus）：hifiasm 在 10× 覆盖下没有组装出该位点（论文真实案例：HG01123 的组装在 chr20:17563000-17563300 断掉，35 个未覆盖区域之一），minigraph 把 HG01361 的组装比对到 CHM13 骨架上，该位点无 SV，得到一条长顶点；Cactus 的 remap 只能从**存在的组装序列**里补 SNP/indel，HG01123 的序列根本不在输入里。MGC 图在该位点 = 10UT，读段比对 NM = 2，两个变异永远进不了图。这正是图 5(b)(c) 的对照：10UT 和 MGC 都是单条长顶点，只有 10UT-AUG（图 5(d)）里有气泡和 1bp 顶点。参考路线（minimap2 + DeepVariant + vg construct）：这个位点不难，DeepVariant 大概率能把两个变异都叫出来，嵌入后的图与 PALSS 的相同。区别不在结果，在代价结构：每个新样本要全基因组比对加基因分型，而且在重复区和复杂 SV 区这条路会失败。PALSS 在这两类区域之外与参考路线殊途同归，在组装路线失明的地方仍然工作。

**简化声明。** 玩具图只有 81bp，specific string 定义要求的**所有真子串在图内出现**在玩具尺度上不严格成立（几十 bp 的串在 3Gbp 基因组里到处都有，玩具里没有这个冗余），所以窗口按真实基因组上的理想行为构造；读段纠错后假设 9/10 无错；假设同簇所有读段选中同一锚点对（论文的区间聚类会合并邻近锚点对，v0.1 代码不会，见 3.4）。这些简化不影响机制本身的呈现。

## 4. Experiments

### 4.1 实验协议

数据。图由 HPRC 变异集对 T2T-CHM13 参考用 vg 构造：n 个随机个体（n ∈ {1,2,4,8,16,32}），n 个个体的图含 2n+1 条单倍型（每人两条 + 参考）；重复变异按 vg 的定义去重（染色体、位置、等位基因全同算重复）。增广实验在 chr20 上做，锚点覆盖实验在 chr1、chr11、chr20 上做。新个体从 HPRC 随机选，保证不在图中；读段用 pbsim3 按 HiFi 参数从新个体两条单倍型模拟，每单倍型 5×（共 10×），再经 hifiasm 纠错。

对照图。FULL：直接对 n+1 个个体（含新个体）用 vg 建图，上界参照。10UT：n 个个体，增广起点。10UT-AUG：10UT 经 PALSS 增广。FULL-AUG：对 FULL 也跑一遍增广，理想情况下不应新增任何东西，是假阳性对照。MGC：hifiasm 组装新个体加 n 个已知个体（已知个体用 bcftools consensus 从 HPRC 变异集生成），Minigraph-Cactus 建图，组装质量用 quast 评估（Supp Table B）。

指标。把新个体的模拟读段用 minigraph 比对到各图，看编辑距离（NM 字段）和两图间匹配残基数差（ΔMatches）；只统计覆盖读段 80% 以上的比对，同一读段多条比对取**匹配残基/比对长度**最高者；顶点支持度 = 覆盖该顶点的比对条数。稳健性检查用 GraphAligner 重跑（Supp B）。运行时间和内存见 Supp Section A，本次材料不含附录，这两个数字无法核实，这是本笔记在代价维度上的信息缺口。

### 4.2 Comparison experiments

#### E1 — solid anchor 覆盖实验

- 检验主张：solid anchor 足以锚定人类基因组绝大部分区域的 specific string，即锚定机制的可行性（贡献 1 的地基）。
- 设置与对照：32 个个体、chr1/11/20 的图，k=27；扫描 T2T-CHM13 参考上相邻 solid anchor 间距超过 15kbp（典型 HiFi 读长）的区域，这些区域是方法的盲区。再用 10× 的 chr20 真实 ONT R10.4 读段（引文 [23]，未纠错）验证真实读段上锚点的丰度。
- 关键结果：488 个无锚点间隔 >15kbp 的区域，合计占三条染色体 3.4%（chr1 4.8%、chr11 1.0%、chr20 2.6%）；最长约 197kb，落在 chr1 着丝粒内（chr1:125983206-126180483）；这些区域全部与已知困难区域相交（简单重复、卫星 DNA、LINE、着丝粒、节段重复，图 2a）。ONT 读段 26198 条中 99.4% 有 ≥2 个锚点，99% ≥7 个，98% ≥26 个，锚点数与读长强相关（图 2b）。
- 定性现象：锚点沙漠与已知难区精确重合，说明覆盖缺口不是方法缺陷，是这些区域本身没有可唯一锚定的 k-mer。
- 能支持的结论：在三条染色体、两类真实测序平台上，锚定机制覆盖绝大多数读段。支持强度高，但只测了三条染色体。
- 不能支持 / 混杂因素：只数了**锚点存在**，没测**锚点定位正确率**。一个 k-mer 满足 solid 条件不代表它被查到时一定对应正确位点（见 5.2 的最脆弱假设）。另外 3.4% 的盲区集中在节段重复和着丝粒，恰好是泛基因组最想解决的地方，不能当小数字忽略。

#### E2 — 增广图上的读段比对改善

- 检验主张：增广图捕获了新个体的变异，即**增广到读段比对与 FULL 一致**这个验收目标（贡献 2、3 的核心）。
- 设置与对照：chr20，n ∈ {1,2,4,8,16,32}；新个体模拟 HiFi 读段比对到 FULL、10UT、10UT-AUG、MGC 四个图。
- 关键结果：10UT-AUG 上读段的编辑距离分布与 FULL 非常接近，n 越小差距越大（n=1 时 10UT 与 FULL 的差距最大，全是新个体的独有变异，图 3a）；FULL 与 10UT-AUG 的 ΔMatches 中位数对所有 n 都是 0（图 3b）。n 增大后各图差距收敛，符合预期：新个体贡献的新变异随图内个体数减少。
- 定性现象：少量读段在 10UT 上比在 FULL/10UT-AUG 上匹配更多。作者解释（4.2 节）：FULL 和增广图里密集的小气泡会让 minigraph 产出部分比对，10UT 的平滑长顶点反而全比对上。只统计完整比对时该现象大幅消失（Supp Fig B）。这提醒我们：minigraph 是为**只含 SV 的稀疏图**设计的，把它当评价器用在 SNP 密集的图上，读数要小心。
- 能支持的结论：增广图的对齐友好程度达到 FULL 水平。支持强度中。ΔMatches=0 是强信号，但它是间接指标。
- 不能支持 / 混杂因素：比对改善不等于变异正确。没有与 HPRC 真值变异集做逐位点对照（作者手上有真值却没用，见 4.3 与 5.2）；评价比对器 minigraph 的偏置作者自己承认了一部分（对 MGC 的偏置），对 FULL 的同样偏置没有讨论；vg augment 可能造环，能用的比对器受限，GraphAligner 复现（Supp B）说结论不变但细节未知。

#### E3 — 增广精度（顶点支持度）

- 检验主张：新顶点几乎全部是真实变异，假增广少（贡献 3 的精度面）。
- 设置与对照：10UT-AUG 与 FULL-AUG 的新增顶点数，按被 ≥1 条比对覆盖的比例和支持分布评估。FULL-AUG 是核心对照：对已经包含该个体的图跑增广，理想输出应为空。
- 关键结果：n=1 时 99%、n=4 时 95% 以上的新顶点被至少一条比对覆盖（图 4a）；FULL-AUG 的新增顶点远少于 10UT-AUG，且几乎全是支持 1 条读段的顶点（图 4b,c）。支持 1 的顶点在 10UT-AUG 里也有不少：n=1 时 2144/34968，n=8 时 1610/8640。10UT 图新顶点支持度的中位数和峰值在 5×，恰好是 10× 测序覆盖的一半，是杂合变异的特征签名。
- 定性现象：支持度峰在 5× 这个事实是全文最漂亮的一个自洽证据：PALSS 加进去的大部分是杂合变异（一条单倍型上的变异，只有一半读段携带），支持分布精确落在覆盖率的一半。
- 能支持的结论：增广内容以真实变异为主，残留错误集中在支持 1 的低置信区。支持强度中。
- 不能支持 / 混杂因素：被比对覆盖不等于该顶点序列正确，错位增广（内容对、位置错）在这个指标下也算**被支持**；FULL-AUG 的支持 1 顶点证明错误残留存在，但没按基因组区域分层（重复区内外各占多少）；部分支持 1 顶点可能是真变异而 minigraph 没比对上（作者自己也承认，因 clip 丢失），这个混淆没有解开。

#### E4 — 与 Minigraph-Cactus 对比及组装盲区案例

- 检验主张：读段增广与组装路线（MGC）质量可比，且在组装盲区能补上 MGC 漏掉的变异（贡献 3 的差异化面）。
- 设置与对照：MGC 从 hifiasm 组装（新个体，10×）+ n 个已知个体组装建图；与 10UT-AUG 对比读段比对质量；再手工检查 hifiasm 没组装出的 35 个 chr20 区域（0.16%）。
- 关键结果：读段比对到 MGC 图平均略好于 10UT-AUG（图 3b），少数读段反而在 10UT-AUG 上更好；作者声明对比可能系统性偏向 MGC，因为 MGC 的建图工具就是 minigraph 本身，产出的是 minigraph 最**顺手**的图。手工检查：35 个未组装区域里有 15 个含 65 个新个体特有变异（相对 n=1 的 10UT），多数区域每单倍型读段覆盖 <2 条，部分在端粒和着丝粒；PALSS 在其中的 10 个变异上正确增广了图，MGC 全部漏掉。案例位点 chr20:17563000-17563300（图 5）：HG01123 纯合的 1bp 插入 A 和 C>T SNP，10UT 和 MGC 都是单条长顶点，10UT-AUG 有 C>T 气泡和 1bp 顶点 A。
- 定性现象：图 5(a) 的读段堆叠显示两个变异都是纯合 alt，图 5(d) 的新图精确复现了两个变异。这是全文唯一的端到端可视案例。
- 能支持的结论：在组装失明的区域，读段增广仍然工作。支持强度弱到中：10 个变异的数字来自人工审查，样本量小。
- 不能支持 / 混杂因素：对比没有做成本归一化，MGC 的输入（完整组装）比 PALSS 的输入（读段）贵得多，接近即可算赢，但论文没量化两边的时间和内存（Supp A 缺失）；MGC 对比只在 n=1 的场景报告了盲区案例；模拟读段与真实读段的行为差异在这个实验里没有对照。

## 5. Limitation

### 5.1 作者明确报告

- 需要高质量或已纠错的读段；未来工作方向是放宽这一约束（结论部分）。
- 只支持无环变异图：聚类步骤依赖顶点拓扑序（Preliminaries）。环图上方法不可用或需改造。
- 增广只加顶点和边，**不更新图内单倍型路径**（结论部分）：新个体在图里了，但图没有对应它的路径。这直接限制渐进式增广：增广后的图没有新个体的路径，下一轮 PALSS 无法在其上重建 FMD-index（推断，见 5.2）。
- vg augment 可能产生环，增广后的图不保证无环，评价和下游使用受限于容忍环的工具（4.2）。
- 共识对多条路径逐个对齐是管线主要瓶颈（见本文 3.5）；未来用对子图的动态规划替代（引 RecGraph [4]）。
- 未做 SV 的同时检测；支持 1 的新顶点里混着测序错误和因 clip 丢比对的真变异，未来要改进辨别（4.3、结论）。
- 作者承认增广问题没有完全解决，本文是动态图构建方向的第一步（结论）。

### 5.2 基于论文材料的解析推断

**最脆弱的假设：锚点唯一性，即 solid anchor 在图中与读段中的唯一性可以替代比对。** 整个方案的定位正确性押在这一条上。solid 条件只保证 k-mer 在单个顶点内唯一且每单倍型至多一个拷贝，但锚定做的是**跨位点**判定：读段上某个 k-mer 命中 sketch 时，算法默认它来自它唯一出现的那个顶点。这个默认可在两种情形下失效：(a) 读段携带图外重复拷贝，新拷贝的侧翼 k-mer 恰好与图内某处一致（节段重复扩张、VNTR 扩增，人类基因组最常见的结构变异类型之一）；(b) 锚点本身在图内唯一、但读段上它的正确来源位点两侧没有锚点，而远处恰有一个同序列锚点，拓扑序启发式会选**最近**的候选，如果正确候选不存在，最近的不再是最近似。E1 只测了锚点**存在性**（96.6% 覆盖、99.4% 读段可锚定），没有测锚点**定位错误率**，论文没有给这个最关键的数字。更麻烦的是失效区与价值区重合：3.4% 的锚点沙漠集中在节段重复、着丝粒、卫星 DNA，这些正是泛基因组想解决线性参考失败的区域。也就是说，方法在最需要它的地方最不可靠，论文对此只有一条间接线索（E1 的盲区列表），没有失效实验。

**最小复现实验：锚定正确率审计。** 不需要复现整条管线。取论文同款设置（n=1 的 chr20 图、k=27 sketch、pbsim3 模拟读段），把读段用 minimap2 比对到 T2T-CHM13 得到真值坐标，跑 palss 的 sketch 加 sfs 两步，对每条 anchored specific string 检查两个锚点的 (顶点, 偏移) 换算回参考坐标后是否落在真值位点两侧（允许 ±1kb）。输出两个数：整体错锚率，以及按区域分层（节段重复内/外、锚点沙漠边缘内/外）的错锚率。若重复区内错锚率显著高于区外，锚点唯一性假设被证伪的代价就量化了；若区内外都低于 ~1%，这个方案的地基就站得住。再补一刀：把图内个体换成含有节段重复差异的个体对（HPRC 里有现成的 segdup 差异样本），看错锚率是否随重复内容增加。这个实验一两天工作量，直接回答论文没回答的问题。

**最强反例设计：图外节段重复拷贝。** 构造一个 PALSS 可预测失败的场景：新个体在某节段重复区比图内个体多一个拷贝。具体地：用 pbsim3 从一条携带 2kb 图外序列（两端各有 500bp 与图内某 segdup 区域同源）的人工单倍型模拟读段，图保持 n=1 的 chr20 图。预测：(1) 新拷贝内部的 k-mer 全部不在图内，specific string 会报出整个 2kb 区域；(2) 其侧翼 500bp 的 k-mer 在图内出现于原 segdup 位点，且可能出现在多个位点，锚定要么选中错误位点、要么 20 个候选锚点全在错误位点；(3) 由于 v0.1 代码按相同锚点对聚类，错误位点的锚点对一致，错误被**团结**成一个看起来支持充分的簇，共识对齐到错误路径，增广把新拷贝的内容接在了原 segdup 位点上，或干脆因路径不匹配被丢。无论哪种结果，都说明：mapping-free 的卖点（回避重复区比对伪影）恰恰在重复区变成 k-mer 歧义的另一种伪影。这个反例同时提供替代解释：图 3 的比对改善可能部分来自**图结构变顺**而非**序列变对**，因为支持度指标（E3）不区分内容正确和位置错误。

**Follow-up Research Idea：把增广从确定性图编辑改成带证据置信的概率标注。** 驱动力是论文自己暴露的缺口：FULL-AUG 显示假顶点几乎全是支持 1，10UT 里支持 1 的顶点却混着真变异（因 clip 丢比对），支持计数与真伪的关系在低覆盖和重复区会崩坏。现在的处理是硬阈值 s=2，丢弃一切低于它的证据，也全盘接受高于它的证据。新 framing：增广图的新顶点、新边自带一个置信度，由簇级统计量（支持读段数、簇内序列一致性、锚点错配分数、位点重复度、读段质量值）经模型给出，而不是由单一计数阈值决定。这一步把 pangenome 增广从图编辑问题变成证据推断问题，与相邻领域有两个接口：统计变异调用的基因型似然传统（DeepVariant 之前的世代：贝塔-二项混合模型拟合读段证据），以及单细胞测序的错误模型。与 vg call 的基因分型不同，这里不需要参考和基因分型，直接从簇统计量出置信，保持 PALSS 的免参考性质。第一个实验完全在论文数据上可做：把 FULL-AUG 的新增顶点按**真变异或噪声**打标（用 HPRC 真值 VCF 判），以簇的 (支持读段数, 簇内 POA 一致率, 锚点唯一性, 位点是否在重复区) 为特征训练一个小的校准模型，验证它能比 s=2 阈值在相同假阳性率下救回更多被 clip 掩埋的真变异（论文 4.3 承认的 2144 个支持 1 顶点就是候选池）。如果校准模型在重复区内外行为不同，那就直接量化了**最脆弱假设**的失效代价，把本文的两个未解问题（错误残留、锚点歧义）合并成一个可解的问题。
