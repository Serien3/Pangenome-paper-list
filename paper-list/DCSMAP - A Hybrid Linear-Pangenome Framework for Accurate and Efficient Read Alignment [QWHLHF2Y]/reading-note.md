## 重建知识边界与作者的思考路径（重要）

### 从已有能力出发，而不是从 DCSMAP 的模块出发

短读长比对的输入是测序得到的一小段 DNA，输出是这段 DNA 在参考上的位置和碱基对应关系。困难不只是找相似字符串。真实个体有两套染色体，参考基因组只给一个固定序列；基因组还包含大量近似重复片段。read 与参考不匹配，可能是测序错误、真实变异，也可能是找错了拷贝。

已有的 BWA-MEM2 可以很快在单一参考上找到候选位置。它的问题不是完全不能比对带变异的 read，而是参考等位基因天然更容易得到完整、高分的匹配。例如真实 read 跨越一个参考中没有的 20 bp 插入，线性比对必须支付一个缺口代价，或者把这段软剪切掉；来自参考等位基因的 read 则不需要。下游在同一个杂合位点看到的 ALT 支持数因此可能偏少。这是**参考偏倚（reference bias）**，不是简单增加线程或延长搜索就能消掉的表示不对称。

到本文之前，vg 与 HPRC 已经提供另一种表示：把多个群体单倍型放进图里，让不同等位基因对应不同路径。对上述 read，含插入的路径能提供完整匹配。但更丰富的参考也会增加竞争位置。在两个同源拷贝都与 read 相似时，图比对可能降低置信度，甚至把支持变异的 read 分配到另一个位置。**参考更全面，不等于每一条 read 都会比对得更好。**

Sirén 等的 Personalized pangenome references（2024）已经把群体图缩减成更接近样本的图。用样本 reads 中的 k-mer 支持选择相关单倍型，就不必对所有个体的替代路径都进行同样的搜索。这一步压缩的是参考。它仍留下一个问题：即使参考已经缩小，为什么每一条简单 read 都必须走图比对？Two-step Graph Mapper 已经证明先缩小搜索空间再做线性比对可行；HiFiCCL 在长读长组装任务中也把线性未比对 reads 送到图。这些前作使选择性调用图算法成为合理起点，不能把混合思想本身全归于本文。

### 一条可能的方法生成路径

以下是**根据前人能力和本文设计重建的推理，不是作者真实实验日志**。

最朴素的混合方案是只重比对 unmapped reads。对一条已被错误放到同源拷贝、或者只剩一半碱基被比对的 read，这条规则输出的仍然是保留。它没有修复参考偏倚，因为有偏的 read 不一定完全没有位置。

下一步可以按低 MAPQ 或不正常的配对关系筛选。这里 MAPQ 是比对位置置信度的数值；proper-pair 表示双端的位置、方向和距离符合比对器的配对标准。这两个信号便宜，而且已经包含搜索过程的结果。问题是软剪切、indel、错配质量和片段长度会共同影响是否值得重比对，单一阈值不一定适用于所有文库。把这些廉价信号组成分类器，是一个自然的工程选择。不过这一步并不证明必须使用 XGBoost，简单规则能做到多少仍要做实验。

分类器需要标签。真实全基因组数据通常没有每一条 read 的实验真值。最容易获得的替代标签是先把同一批 reads 在线性和图上都跑一遍，记录结果是否不同。这里发生了关键的概念替换：原本想预测的是**图比对是否会改善结果**，实际训练的是**两条流程是否会产生分歧**。只有当分歧经常意味着线性流程有问题时，这个替代目标才好用。作者的底气来自既有泛基因组方法平均更准确的经验，而不是逐条 read 的正确性证明。

选择性重比对又产生合并问题。图上的路径必须投影到共同的 GRCh38 坐标，两个来源的 indel 表示还可能不一致。只给图分支做局部重比对省时；合并全部 reads 后再做，则能利用更多局部证据。于是出现 dcsmap 与 dcsmap-m1 两种顺序。与此同时，线性比对和建图可以并行，但内存相加可能超过服务器预算，迫使工具级实现继续减内存。

这条推理最终导向的是一个计算分配问题：**把昂贵的参考表示用在确实需要它的数据上，并保留便宜流程已经提供的有效证据。** 本文向更一般的系统问题提供了一条经验：更强的候选解空间有时会引入更多歧义，少算一些既可能省钱，也可能保住原本稳定的结果。

### 作者的把握程度与真正的贡献边界

作者在 Discussion 明确承认分歧标签只是近似，并把超过全图流程的准确率称为意料之外。对同源路径导致假阴性的解释使用的是观察性证据；没有直接移除路径再观察恢复的因果实验。对优化不影响准确率，正文则从未发现统计显著差异推到不改变准确率，这个措辞偏强。未检出差异不等于证明两者等效。

据本文 Results 判断，作者最硬的证据是多个真实样本上的下游变异结果、等位平衡和可测的运行时间，而不是分类器的 AUROC。特征增益高度集中在两个常识信号上，也提示本工作的价值主要是**流程组织与工程实现**。没有消融证明复杂学习器不可替代；没有源码级说明足以重建全部性能优化。也不能从没有附录原件推测作者经历过什么审稿要求。

- **Problem：** 在约 30× 人类双端短读长 WGS 中，用线性比对已产生的廉价信息选择少量 read pairs 送入个性化泛基因组，使小变异检出与参考偏倚接近或优于全图流程，同时减少 CPU 时间和墙钟时间。
- **Motivation：** 图参考能减少非参考等位基因的证据流失，但全量图比对和重比对增加计算成本。若大多数 reads 不需要图表示，就可在已有 CPU 服务器上保留大部分收益。
- **State of Research / Gap：** BWA-MEM2 提供高效线性比对；vg giraffe 提供图比对；HPRC 提供多样性；haplotype sampling 提供样本相关子图；ABRA2 修复局部 indel 表示；已有混合策略说明选择性计算可行。仍缺的是适用于短读长 WGS 的、从线性 BAM 即可执行的路由与完整整合方案，以及其在准确率和资源上的联合验证。
- **Contribution：** 核心洞见是按 read 的需要分配参考复杂度。技术增量是以比对分歧监督路由、成对分流及两种局部重比对整合、并行流程和工具优化。它推进的是既有算法的组合与计算分配，不是新的图比对算法，也不是首次发明个性化参考或混合比对。

## 1. Abstract｜全篇压缩

### 1.1 Task

对人类 WGS 双端短 reads 生成兼容线性坐标的比对结果，供小变异检测使用。重点是兼顾 SNP/indel 检出、杂合位点等位平衡、运行时间和峰值内存。

### 1.2 Technical challenge for previors methods

单一参考使非参考序列在比对时吃亏；群体图虽然提供更多真实路径，也带来更多搜索和竞争位置。个性化图缓解了参考复杂度，却仍对所有 reads 支付图比对成本。仅按 unmapped 状态分流还会漏掉已经比对但位置或局部表示不可靠的 reads。

### 1.3 Key insight / motivation

**便宜方法已经给出稳定答案的数据应保留原结果，只让需要额外参考信息的数据承担更复杂的计算。**

### 1.4 Technical contributions

- **用线性比对特征做成对路由：** 用 25 个 BAM 特征训练 XGBoost，以线性和图比对分歧为正标签；未比对记录直接进入图分支。将图比对限制在平均 14.80% 的 read pairs。
- **在统一坐标上整合两类证据：** 图比对投影回 GRCh38，比较先局部重比对后合并与先合并后局部重比对；提供时间与 indel 准确率不同的选择。
- **把混合流程做成可部署系统：** 流式提取、并行建图，加上 vg 和 ABRA2 的工具优化，将测得峰值内存压到约 104–107 GB。正文未充分披露工具优化的实现细节。

### 1.5 Experiment

17 个约 30× 数据集覆盖 HG001–HG007、DNBSEQ/Illumina 和 PE100/PE150。正文报告两种优化混合流程平均相对 BWA-MEM2–DeepVariant 减少 46.66% 的 FP+FN，相对优化个性化图流程减少 8.39%（Results、图 2–3）。HG002 CMRG 困难区域则略逊于全图流程。HG003 DNBSEQ PE150、32 vCPU 条件下，dcsmap-opt 为 2.17 h，优化全图流程为 3.41 h，原始全图流程为 5.51 h（图 5）。以优化全图为分母，加速是约 1.57 倍，不是 2.5 倍。

## 2. Introduction

### 2.1 Task and application

- 任务定义：输入一对 FASTQ、人群泛基因组及索引和线性参考；输出在 GRCh38 坐标下的排序 BAM，再通过 DeepVariant 产生小变异 VCF。
- 重要性：比对丢失的 ALT 证据不能简单依靠下游变异检测恢复；大量人类样本还要求单样本运行成本可控。
- 应用：本文展示的是人类短读长 WGS 的 SNP 和小 indel 检测及杂合位点参考偏倚评估，没有验证结构变异检测、长读长比对或临床诊断。

### 2.2 Technical challenges for previous methods｜本文真正要解决的问题

#### Technical challenge 1：线性参考造成等位基因证据不对称

**Previous method：** BWA-MEM2 在一个固定参考序列上找种子、候选位置和扩展比对。

**Failure cases / limitation：** 携带插入、缺失或密集非参考差异的 reads 可能被软剪切、低置信度比对或分配到其他位置；杂合位点 ALT 比例偏离 0.5。

**Technical reason：** 真实非参考序列没有独立参考路径，匹配它要支付错配或缺口代价。参考等位基因则没有同等惩罚。这是表示问题，也受比对器启发式影响。

**Research gap：** 本文不重新发明图表示，而是要识别哪些已有线性比对值得借助图纠正，且识别过程本身足够便宜。

#### Technical challenge 2：全量图比对成本高，增加路径也会增加歧义

**Previous method：** vg giraffe 在群体图或经 haplotype sampling 得到的个性化图上比对所有 reads。Two-step Graph Mapper 则先推断较可能路径，再沿路径做线性比对。

**Failure cases / limitation：** 全量图搜索耗时；个性化后仍残留的同源路径可能降低 MAPQ 或使某些位点覆盖下降。

**Technical reason：** 参考选择发生在图层面，不等于每条 read 都需要额外路径。短 read 的信息有限，额外候选有时增加不确定性，而不是增加定位证据。

**Research gap：** 在同一个样本内，保留线性方法的稳定定位并选择性调用图方法。线性与图谁更可靠应是有条件的判断，不能仅凭平均准确率统一替换。

#### Technical challenge 3：没有 read 真值，还必须保证双端和坐标一致

**Previous method：** 只救 unmapped reads 的混合策略容易执行；全量图比对不需要学习分流标签。

**Failure cases / limitation：** 已经错放的 reads 不被救回；逐条 mate 独立输出会破坏配对；图和线性记录直接拼接可能出现染色体名称或局部 indel 表示不一致。

**Technical reason：** 可观察到的是比对器自报的置信度，不是真实来源。双端与局部位点证据还存在依赖，不能把每条记录完全独立处理。

**Research gap：** 用可获取的分歧监督学习低成本路由，并按 read-name group 整体分流，在共同坐标和元数据约定下合并。

### 2.3 Our pipeline：如何解决 challenge

#### 2.3.1 Key innovation / insight / contribution

将参考复杂度的选择从全样本统一决定，改成逐对 reads 决定；已经比对的结果同时充当路由的证据。

#### 2.4.2 Contribution 1：用比对分歧训练廉价路由

**Problem addressed：** 捕获不止 unmapped 的可疑线性比对，同时避免全量图搜索。

**Approach：** 从同一训练样本的两条完整流程构造分歧标签，从线性 BAM 提取配对、MAPQ、错配、indel、软剪切和质量特征，再成对分流。

**Advantage/insight：** 不需要外部区域注释，部署可嵌入 BWA-MEM2 输出流。跨样本下游改善支持流程实用性，但不能把 AUROC 解释为路由到正确位置的准确率。

#### 2.4.3 Contribution 2：整合流程与运行代价一起设计

**Problem addressed：** 分支的坐标、局部表示和运行资源不能自然兼容。

**Approach：** 图比对投影回线性坐标，ABRA2 分别在图分支或合并后的 BAM 上运行；将建图与线性比对并行，并优化建索引与局部重比对。

**Advantage：** dcsmap 节省局部重比对工作，dcsmap-m1 通常有更好的 indel 指标。图 5 提供了可测的时间与内存交换，而不只是算法复杂度主张。

### 2.5 Demos / applications

论文最直观的应用展示是图 4：在 HG003 DNBSEQ PE150 的杂合 indel 位点，线性流程的 ALT 支持比例偏低，混合流程将其拉近 0.5。后文 3.7 用构造的短序列跟踪原因；该例不是论文真实 read，也不把示意输出冒充软件运行结果。

## 3. Method

### 3.1 Overview

#### 具体的任务

- 输入：双端 reads；GRCh38 对应线性参考；HPRC 群体图 GBZ 与单倍型索引；训练好的 XGBoost 模型。
- 输出：包含每对输入 reads 的一个分支结果、坐标排序并索引的 BAM。图来源与线性来源可通过标签区分。变异检测是本文评测输出，不是路由器直接输出。
- 目标：把图计算集中到可疑 reads，同时避免双端分离、重复计数和染色体名称不一致。

#### 方法总体流程

![图 1：共享上游与两种合并顺序](images/87facdb5adba02518f585baa7ca3566e2ecf4d7ac523e89ed769f72f1f1412e9.jpg)

所有 reads 同时进入两个任务。一边 BWA-MEM2 做快速线性比对并由 extract-bam 分流；另一边 KMC 从**全体原始 reads** 统计 k-mer，vg haplotypes 生成样本相关图并建立索引。两边就绪后，只有选中的 reads 用 vg giraffe 重比对，再投影到 GRCh38。两种最终策略为：

\[
\mathrm{dcsmap}=L_{\rm keep}\cup A(G_{\rm selected}),\qquad
\mathrm{dcsmap\!\!\;m1}=A(L_{\rm keep}\cup G_{\rm selected}).
\]

这里 $L_{\rm keep}$ 是保留的线性比对记录集合，$G_{\rm selected}$ 是已投影的图比对记录集合，$A$ 是 ABRA2 局部重比对操作。并集表示按相同坐标和元数据约定合并 BAM，不是同时保留一条 read 的两个相互竞争的 primary alignment。由于 $A$ 使用局部输入证据，通常不能把它分配到并集的各项上，故两种顺序不等价。

### 3.2 Pipeline module 1：构造分歧标签与训练 XGBoost

**Motivation：** 真实数据没有逐 read 的来源真值，但可以比较两个已有比对流程的输出。

**做法：** 对 NA12891、Illumina NovaSeq PCR-free、约 30× 数据分别运行快速 BWA-MEM2 与个性化图 vg giraffe 加 ABRA2，按 read name 比较 primary records；将一致视为负类，将位置、indel 或 missing-mate 分歧视为正类。排除仅 MAPQ 不同和 unmapped 类，再下采样负类训练模型（Methods: Training labels and data partitioning）。

**为什么能 work：** 配对异常和低置信度通常与两种参考上的放置分歧相关。假如其中足够多的分歧是线性方法遗漏真实变异造成的，捕获分歧就能改善下游。

**Technical advantage：** 标签可自动大量生成，推理只依赖线性 BAM。代价是标签含噪，且把图结果不同与图结果更好混为一个学习目标。

#### 数据从不平衡变成近乎平衡

| 标签类别 | 原始比例 | 训练处理 | 部署处理 |
| --- | ---: | --- | --- |
| SAME | 84.13% | 随机保留 12.5% | 由模型预测 |
| 位置、indel、missing-mate 分歧 | 10.86% | 正类全部保留 | 由模型预测 |
| 仅 MAPQ 不同、unmapped 两类合计 | 5.01% | 均排除；正文未给各自比例 | 前者一般仍需模型；含 unmapped record 的 group 直接进图 |

SAME 从 629,756,084 条降至 78,722,985 条，最终表有 160,010,424 条 read，负类 49.2%、正类 50.8%。分层随机划分为训练/验证/测试 80/10/10。注意这是 **read 数**，后面的 14.80% 是 **read-pair 路由率**，二者不可直接互换。

令 $y_i\in\{0,1\}$ 为第 $i$ 条 read 的分歧标签，$x_i\in\mathbb R^{25}$ 为特征向量，$p_i=f(x_i)$ 为 XGBoost 分数。它试图让正类的 $p_i$ 大、负类的小。正文以验证 log loss 做 early stopping；二分类 log loss 的含义可写成：

\[
\ell_i=-y_i\log p_i-(1-y_i)\log(1-p_i).
\]

正类预测 $p=0.9$ 的损失约 0.105，预测 $p=0.1$ 则约 2.303。这里惩罚的是分歧判断错，不是最终 variant call 错。本文没有给出完整训练 objective 和正则化配置，不能从这个解释式恢复所有训练参数。

#### 25 个特征实际承载什么信息

| 输入/量 | 类型与形状 | 在机制中的含义 |
| --- | --- | --- |
| 单条 read 的 $x_i$ | 25 维实数向量 | 从 BAM 提取的便宜证据 |

| 片段长度标准化值 | 标量 | 相对当前文库片段长度分布是否异常 |
| MD 派生计数 | 多个标量 | 错配总数及四个碱基质量区间的错配数 |
| CIGAR 派生计数 | 多个标量 | 插入、缺失的次数与平均长度，软剪切碱基数 |
| read 端部与局部质量特征 | 多个标量 | 距端点 10 bp 内的事件计数/比例，事件附近 ±5 bp 的平均质量 |

MD 描述参考匹配、错配与缺失；CIGAR 描述比对操作。`10M2I8M` 消耗 20 个 read 碱基、18 个参考碱基，表示中间有 2 bp 插入。`10M10S` 只将前 10 bp 对到参考，其余 10 bp 软剪切。M 不保证每个碱基都完全匹配，错配还要结合 MD 或参考检查。

文库长度为 350 bp、标准差为 50 bp 时，450 bp 对应一个常见 z-score 示例 $(450-350)/50=2$。这是解释标准化的例子，**正文未给实际估计器、截尾策略或零方差处理**，不能认定 extract-bam 就使用这一具体实现。类似地，四个质量分箱边界、25 列的完整顺序在本地材料里不全，不能凭概述拼成可复现的模型输入。

Optuna 对 9 个超参数搜索 80 次，最终 100 棵树、最大深度 10、learning rate 0.269；early stopping patience 为 30，以验证 log loss 为指标，最后保留全部 100 棵树。验证 log loss 从 0.49181 降到 0.13341。剩余六项超参数、搜索范围、随机种子和各 trial 结果未见。特征 gain 中 proper-pair 占 69.4%、MQ 占 22.2%，合计 91.6%；前五项占 97.0%。**gain 是树分裂收益的归因，不是移除特征后的准确率损失。**

#### 为什么 0.5 不是现实中的 50% 错误概率

假设原始已纳入类别中，正类后验概率为 $p$；负类以 $s=0.125$ 的概率保留，正类全保留。理想校准模型在下采样分布给出的概率为 $q$：

\[
q=\frac{p}{p+s(1-p)},\qquad
p=\frac{s q}{1-q+s q}.
\]

当 $q=0.5$ 时，$p=0.125/1.125\approx0.111$。当 $q=0.9$ 时，$p\approx0.529$。推导只是把保留下来的正负比例重新归一化，前提是类内随机采样且模型已校准；论文没有证明这些部署校准条件。这个计算说明下采样让 0.5 阈值更容易选中原分布的疑难 reads，而不是证明部署错判概率是多少。还要记住标签本身是分歧，不是错误。

### 3.3 Pipeline module 2：流式成对分流

**Motivation：** 如果先写全量 BAM 再读回来，路由本身会引入额外 I/O；如果分别分流双端，后续配对会失去一致性。

**做法：** `bwa-mem2 mem -Y -S -r 3 -y 0` 输出到 C++ extract-bam；按 read name 组织两个 mates 及全部 primary/secondary/supplementary records。任一记录 unmapped 即整组入图；其余按两个 mate 分数的 OR 规则判定（Methods: Streaming inference and read partitioning）。

**为什么能 work：** 一端已经暴露出异常时，把另一端同时交给图比对能保留配对约束。以整组为单位也避免 supplementary records 分散在两份结果。

**Technical advantage：** 未选中的记录直接进入 samtools sort，不需要中间全量 BAM；代价是批处理缓冲、gzip FASTQ 输出和后续重读仍然存在。

设 $u_j\in\{0,1\}$ 表示第 $j$ 个 read-name group 是否含 unmapped record，$p_{j1},p_{j2}$ 为两端分类分数，阈值 $\tau=0.50$。路由标志为：

\[
r_j=u_j\lor[p_{j1}\ge\tau]\lor[p_{j2}\ge\tau].
\]

例如分数 $(0.08,0.73)$，整对被选中；不是把平均值 0.405 与阈值比较。一个 mate 无位置时，无论另一端多可靠，$u_j=1$ 都直接触发路由。本文对 secondary/supplementary 记录具体如何参与特征评分的描述不够细，但对整组保留、unmapped 触发和两端 OR 是明确的。

producer 组装 read-name groups，以 4,000,000 records 为一批交给 consumers；consumers 估计本批片段长度分布、提取特征并批量调用 XGBoost C API；一个 writer 序列化输出。选中的 reads 恢复原始测序方向后写成配对 gzip FASTQ。负链比对记录需要正确恢复序列方向及质量顺序，否则重比对接到的已不是原始 read。未选中的记录保留 BWA-MEM2 结果并排序。

`-S -r 3 -y 0` 的组合跳过 mate rescue、减少 reseeding，作者报告线性阶段从 1.44 h 到 0.73 h。它不只是等价的实现优化，而是改变搜索敏感性的参数选择。训练标签也基于这一快速配置，所以模型学到的部分异常可能来自特意简化的第一阶段。这种交换合理，但必须和工具级输出近似等效的加速分开讨论。

### 3.4 Pipeline module 3：个性化图、选中 reads 的重比对与投影

**Motivation：** 群体图含大量与样本无关的分支。选中困难 reads 后，仍应缩小它们面对的参考空间。

**做法：** 全部 FASTQ 经 KMC 统计 k-mer，连同 GBZ 和单倍型索引送入 vg haplotypes；保留指定线性参考路径，采样局部相关单倍型形成 diploid personalized subgraph，再建 distance 和 minimizer 索引。选中的 pairs 用 vg giraffe 比对并投影到 GRCh38（Methods: Personalized pangenome construction；Linear and graph alignment）。

**为什么能 work：** 样本序列中频繁出现的 k-mer 为相关单倍型提供支持；减少无关路径可降低竞争与搜索工作。图保留真实非参考分支，使带变异的 read 有机会完整匹配。

**Technical advantage：** 同时在参考端缩减路径、查询端缩减 reads。代价是样本图与索引仍要构建，且短 k-mer 支持不能保证重复区单倍型选择正确。

以 $k=3$ 的示意序列 `ACGTT` 为例，滑窗给出 `ACG`、`CGT`、`GTT`。一条候选单倍型若包含这些有支持的词，比完全缺少支持的路径更符合样本。真实人类图不会用这个极小例子的 $k=3$；本地正文没有给 KMC 的具体 k 和所有参数。这里仅解释 k-mer 如何连接 reads 与参考选择，不能把 haplotype sampling 理解成一条 read 精确选中一个人的整条染色体。

distance index 支持图上位置间距离相关查询；minimizer index 用稀疏的序列代表词寻找种子候选。二者是已有 vg 组件，不是本文新设计。图上匹配结果随后需要投影，也称 surjection：把所走图路径表示为相对于保留的线性路径的比对。参考没有的插入仍可能在 BAM 中表现为 I 操作。**在图上容易匹配，不意味着线性输出坐标本身就能容纳新的染色体位置。**

投影后清理 graph-specific path prefixes，使染色体名称一致，补充 read group 和 alignment-source tag，然后才可合并。本文只详细说明流程，没有给出投影失败、不能投影序列或多重 primary 的完整处理策略。重复区和大量新序列正是这些边界可能重要的地方。

### 3.5 Pipeline module 4：ABRA2 与两种合并顺序

**Motivation：** 同一个 indel 周围的 reads 可能表现成不同的错配、剪切或缺口，直接送入下游会削弱一致的 ALT 证据。

**做法：** ABRA2 在输入 BAM 指示的候选 indel 区域做局部重比对。dcsmap 只对图分支运行；dcsmap-m1 先合并再对全部比对运行（Methods: Alignment integration and indel realignment）。

**为什么能 work：** 局部重比对能把原本分散的 indel 支持整理为更一致的比对。m1 还让保留在线性分支中的 reads 接受同一区域的重比对。

**Technical advantage：** dcsmap 将 ABRA2 工作限制在小子集；m1 用更多局部证据换取通常更好的 indel F1。优化后两种全流程时间相差 0.64 h，约 38.4 min。

这里不能把 ABRA2 只当作 CIGAR 格式整理。输入集合不同，发现的候选区域和局部支持也会不同。某个 read 本身看起来足够可靠因而留在线性分支，但仍可能受益于同一位点其他 reads 暴露的 indel。路由是逐 pair 的，局部重比对依赖位点附近的多条 reads；这两个尺度不一致，就是 m1 可能改善结果的机制解释。论文没有逐 read 消融来量化这种机制贡献，因此这是有依据的解析，而不是已隔离证明的结论。

### 3.6 Pipeline module 5：变异检测与实现优化

**Motivation：** 比对收益最终应体现为变异检出；混合流程若超过内存预算，减少图 reads 也无法部署。

**做法：** 用 DeepVariant v1.10.0 WGS 模型检测 PASS 小变异；线性流程使用标准 make_examples，混合与图流程使用 `min_mapping_quality=0`、`keep_legacy_allele_counter_behavior=true`、`normalize_reads=true`。对 vg haplotypes、distance、minimizer、giraffe 和 ABRA2 优化执行效率及内存（Methods: Small-variant calling；Results: Computational efficiency）。

**为什么能 work：** caller 能综合同位点多条 reads；工具优化减少线程低效和内存占用，支持建图与线性比对并发。

**Technical advantage：** 使用相同预训练 WGS 模型方便比较，性能优化也能用于全图流程。但 make_examples 不完全相同，准确率比较是工作流级比较，不能全归功于 alignment。

DeepVariant 的 small model 默认启用，先处理符合条件且置信度足够的候选，其余交给完整 pileup 图像 CNN。这是下游调用器内部的既有混合推理，不能当作 DCSMAP 的贡献。GATK 对照另有 duplicate marking、条件允许时 BQSR、HaplotypeCaller 和 GenotypeGVCFs，涉及不同 caller，因此它与混合流程的差距更不能单独用来证明比对器优劣。

正文说加速主要来自线程效率，但没有解释具体锁竞争、数据布局、分配器或算法改写。可以报告哪些阶段快了，不能补写成作者采用了某项确定的并行技术。ABRA2 优化更不是免费收益：其阶段峰值由 31.1 GB 增至 89.0 GB。

### 3.7 一个从序列到位点证据的完整小例子

**以下全是教学构造，不是实测。** 把 read 缩到 20 bp，使用人为给定的分类分数和比对输出，省去种子搜索；两端配对仍保留。这个例子展示一个系统允许发生的路径，不预测真实软件必然输出这些 CIGAR。

真实目标位点参考片段是 `ACGTACGTAA CCGGTTAACC`，ALT 在第 10 个参考碱基后插入 `GG`。跨插入的 20 bp read 是 `ACGTACGTAAGGCCGGTTAA`，对应参考的前 18 bp。正确投影的 CIGAR 为 `10M2I8M`。参考图的两条局部路径为：

```text
REF: ACGTACGTAA -------- CCGGTTAACC
ALT: ACGTACGTAA -- GG -- CCGGTTAACC
                      ↑
                 read 跨越此分支
```

准备五对 reads。表中只写与困难有关的一端，另一端保留用于配对。

| pair | 线性分支观察 | 分数 (mate1, mate2) | 路由决策 | 图输出或最终保留 |
| --- | --- | --- | --- | --- |
| A | 唯一位置，REF read，`20M`，MQ60，proper-pair | (0.02, 0.03) | 保留 | 原线性记录 |
| B | ALT 跨插入 read，`10M10S`，MQ12，配对异常 | (0.82, 0.07) | 整对进图 | ALT 路径完整匹配，投影 `10M2I8M` |
| C | 一端 unmapped | 不评分 | 整对进图 | 假定图补回位置，投影 `10M2I8M` |
| D | ALT read 的局部表示欠佳，`10M10S`，但配对正常 | (0.30, 0.05) | 保留 | dcsmap 保留剪切；m1 可利用局部候选改成 `10M2I8M` |
| E | 来自重复拷贝 U，却在 V 得到 MQ60、proper-pair | (0.03, 0.04) | 保留 | 两个混合版本都仍可能错放 |

全量线性基线到此结束时，B、D 的插入碱基仍在 soft clip 中，C 无位置，E 错放。假定下游没有成功从 B、D 的剪切恢复 ALT，这些 reads 没有形成明确的插入支持。

混合流程先保留 A、D、E，将 B、C 恢复成原方向 FASTQ；同时全体五对 reads 都参与 k-mer 统计。假定采样子图含上述 ALT 路径。B、C 完成图比对、投影和 ABRA2 后形成一致插入表示，再与 A、D、E 合并。dcsmap 到此停止；m1 对合并集合再次做同一阶段的局部重比对，假定 B、C 提供足够候选证据，使 D 也形成 `10M2I8M`。E 的问题是拷贝位置，不是同一位置的局部缺口，ABRA2 不能被假定会自动把它从 V 搬回 U。

为把这个过程变成可算的位点统计，将 A 类扩展到 10 条 REF 支持 reads，将 B/C 类合计设为 6 条 ALT，D 类设为 4 条 ALT。E 位于另一个重复区域，不计入此位点。真实比例是 $10/(10+10)=0.5$。假定纯线性只识别出 3 条 ALT，dcsmap 识别出经图救回的 6 条，m1 又救回其余 4 条：

| 阶段 | REF 支持 | ALT 支持 | ALT/(REF+ALT) |
| --- | ---: | ---: | ---: |
| 真值 | 10 | 10 | 0.500 |
| 纯线性示意 | 10 | 3 | 0.231 |
| dcsmap 示意 | 10 | 6 | 0.375 |
| dcsmap-m1 示意 | 10 | 10 | 0.500 |

未被识别的 read 可以还覆盖这个位点，却未被成功归入 REF/ALT 支持。因此这里的分母不是 BAM 中所有覆盖 reads。真实 biastools 会做 context-aware assignment，真实 DeepVariant 也可能从 soft clips 恢复变异，所以该例只说明证据改善的一种机制。

全量图在这个插入位点也可能找回全部 ALT。但对 A 类所在的另一个同源区域，全量图可能把本来唯一的线性定位变成两个竞争位置，降低 MAPQ；混合保留 A 的原位置就可能更好。反过来 E 是同样保留规则的失败：低路由率不是保证，只说明分类器把大多数数据留在快速分支。**同一个设计能保护正确的稳定定位，也能保护错误的高置信度定位。**

对调用器来说，precision 是预测的变异中真变异的比例，recall 是真变异被检出的比例。用简化的统一计数记号：

\[
P=\frac{TP}{TP+FP},\quad R=\frac{TP}{TP+FN},\quad
F_1=\frac{2PR}{P+R},\quad E=FP+FN.
\]

TP、FP、FN 分别是真阳性、假阳性、假阴性计数；实际 hap.py 的 query/truth 表示匹配比这套简单计数更细。相对错误减少为 $\rho=1-E_{\rm method}/E_{\rm comparator}$。基线 10,000 个错误、新方法 5,334 个错误时，$\rho=46.66\%$。这既不是 F1 增加 46.66 个百分点，也不是全基因组准确率增加 46.66%。论文汇总百分比的加权方式需要补充表才能完全重算；不能直接把 17 组的平均相对下降当作所有错误合并后的下降。

### 4.2 Comparison experiments

#### E1：分类器能预测比对分歧吗，能跨配置运行吗

- 检验主张：线性 BAM 特征足以识别大部分分歧，并使图分支保持较小规模。
- 设置与对照：单样本下采样后的 80/10/10 划分；固定模型和阈值部署到 17 组数据。
- 关键结果：验证 AUROC 0.9831、AUPRC 0.9853；阈值 0.50 时 precision 0.9639、recall 0.9598、F1 0.9618。测试与验证各指标差小于等于 0.0002。read-pair 路由率均值 14.80%、中位数 14.16%、SD 2.22%、范围 12.12–19.87%；DNBSEQ PE150 平均 13.23%、Illumina PE150 平均 16.65%（Results；正文转述 S1、S2）。
- 定性现象：分裂收益几乎都来自配对几何和 MQ，说明模型大量复用了比对器已有的置信度信息。
- 能支持的结论：能较好地预测同一训练分布上的流程分歧；跨样本部署没有使图分支比例失控，下游还显示了实际收益。
- 不能支持 / 混杂因素：AUPRC 来自近乎平衡的评测集，不是自然类别比例；没有跨样本 read-level 真值。读段随机划分可能使同一位点乃至相关 mates 分布在不同集合，正文未明确按 pair 或区域分组划分。验证与测试很接近不足以证明没有泛化问题。

AUROC 约 0.98 不是 98% 的 reads 被放对了位置。它衡量正类分歧样本的分数通常是否高于负类一致样本。两种流程都错到同一处时，标签仍为负；图把本来正确的线性 read 搬错时，标签仍为正。这个区别直接决定模型不能被当作可信的错误检测器。

还可核对正文的预测路由率 13.7%。用近似训练正类比例 $\pi=0.508$、recall $t=0.9598$ 和 precision $v=0.9639$，可反推负类假阳性率：

\[
\mathrm{FPR}=\frac{t\pi(1-v)}{v(1-\pi)}\approx0.0371.
\]

再代入原始类别比例，$0.1086\times0.9598+0.8413\times0.0371\approx0.1354$，确实接近 13.7%。但这一简单计算没有单独加入 unmapped、被排除的 MAPQ-only 类，也没有按两端 OR 计算 pair 率。若两端独立且单端概率为 $a$，成对选择率应为 $1-(1-a)^2$；真实 mates 又不独立。因此正文的接近关系只能算数量级自洽，不能独立证明跨平台校准良好。

#### E2：主要基准上的小变异检测

- 检验主张：选择性图比对能保留图参考收益，并超过纯线性和全量个性化图工作流。
- 设置与对照：17 组、GIAB v4.2.1 高置信区域；BWA-MEM2–DeepVariant、BWA-MEM2–GATK、群体图 vg、个性化图 vg、两种混合策略及 origin/opt 版本。
- 关键结果：两种优化混合流程的汇总平均错误数，相对 BWA-MEM2–DeepVariant 减少 46.66%，相对优化个性化图减少 8.39%；单独 dcsmap-opt 相对后者平均减少 8.09%。dcsmap-m1 通常最高（图 2–3；正文转述 S5、S8）。全文未提供可重算全部差值的逐组绝对 FP/FN 表。
- 定性现象：图 3 中 SNP 错误减少的幅度通常高于 indel；m1 对 indel 的额外收益更明显，符合全体 reads 接受局部重比对的机制。
- 能支持的结论：在这些数据与指定 caller 配置下，混合工作流能比两个端点都更好。图分支比例小并不必然牺牲主基准准确率。
- 不能支持 / 混杂因素：没有重复运行或随机种子置信区间；线性和图/混合的 caller 输入参数不同。46.66% 不能归为路由器单一贡献，也不能外推为所有难区、所有 ancestry 或其他测序深度上的效果。

![图 2：DNBSEQ PE150 七个 GIAB 样本的 SNP/indel F1；纵轴非零起点，小幅 F1 差异被放大](images/2994f9859b88f766aa9fceca4a78554dd4daff798fd104b4db8635928d2881ae.jpg)

![图 3：相对优化个性化图的错误减少率；橙色 dcsmap-opt，紫色 dcsmap-m1-opt](images/883188cbeae1357c3dd3639eeaf9cca7542d4d4cf5e8ddd105036ee6a4b87030.jpg)

图 2 的柱高差很小，图 3 的错误减少率却可以达到约一成，二者没有矛盾。当 F1 已接近 1，减少少量残余错误对 F1 只产生很小的绝对变化。应同时报告原始错误数和相对减少，不只选择看起来更大的指标。

#### E3：为什么混合方法能比全图更好

- 检验主张：保留线性定位能避免全图中的竞争路径削弱真实变异支持。
- 设置与对照：HG003 DNBSEQ PE150，dcsmap-opt 与 vg-giraffe-diploid-opt；研究全图独有的 1,793 个 FN 位点。
- 关键结果：FN 占总体错误差的 87%；这些位点全图/混合的中位深度为 16/32；全图中有 198 个位点、占 11.0%，无 read。每位点 MQ≥60 reads 比例的中位数为 0/1.00；混合结果中线性来源比例中位数 97.8%、均值 79.8%（Results；正文转述 S4 图）。
- 定性现象：全图的错误位点经常不是稍差一点，而是丢失大量覆盖或高质量支持；混合提供的支持大多来自保留的线性结果。
- 能支持的结论：覆盖和置信度损失确实与全图特有 FN 同时出现，保留线性证据是合理解释。
- 不能支持 / 混杂因素：先筛选全图失败位点，再观察其证据不足，有条件选择效应；没有对图的竞争路径做直接干预。MAPQ 更高可能是更正确，也可能是更自信，单靠 MQ60 比例分不开。还应对称检查混合独有 FN 及双方不同 FP。

这是论文最有启发性的观察之一，因为它挑战了图方法逐 read 都占优的默认直觉。但它是对失败集合的机制线索，不是所有区域中线性定位更可靠的证明。

#### E4：扩大真值覆盖后，收益能否保持

- 检验主张：主基准结论是否延伸到更复杂区域。
- 设置与对照：HG002 在两平台上使用 v5.0q，并单独查看 CMRG。
- 关键结果：v5.0q 上混合 SNP F1 为 0.9945–0.9948、indel 为 0.9672–0.9758；全图分别为 0.9944–0.9947、0.9667–0.9755；BWA-MEM2–DeepVariant 为 0.9912–0.9916、0.9610–0.9734。CMRG 中混合 SNP 为 0.9865–0.9883、indel 为 0.9680–0.9706；全图为 0.9874–0.9889、0.9711；线性为 0.9757–0.9765、0.9589–0.9600（Results；S6、S7 转述）。
- 定性现象：覆盖更难区域后优势变小；在 CMRG 内排序反转，混合主要损失 recall。
- 能支持的结论：混合相对线性的收益仍在，但高置信线性错误逃过路由是一个真实边界。
- 不能支持 / 混杂因素：范围值混合了平台/工作流，不能把区间端点任意相减成配对收益。只在一个样本上扩展真值，不能估计广泛人群中困难区域的风险。

这一负面结果不是可忽略的边角。若整体均值获益主要来自容易区域，而重要基因的 recall 下降，实际使用者会接受不同的成本函数。论文诚实报告这一点，使路由假设的边界可以被检验。

#### E5：等位平衡能否直接显示参考偏倚减少

- 检验主张：准确率变化不仅是 caller 的数值变化，还反映 ALT read 证据的恢复。
- 设置与对照：biastools、真值杂合位点、高置信区域；HG003 DNBSEQ/Illumina PE150，HG001 DNBSEQ PE100；按 indel 长度分箱。
- 关键结果：正文未提供完整逐箱数字；图 4 显示较长 indel 的纯线性曲线明显低于 0.5，dcsmap 更接近 0.5，m1 与图流程较接近。图中点是均值、竖向刻度是第 25/75 百分位，**不是均值置信区间**。
- 定性现象：SNP 附近方法更接近，较长插入/缺失更能暴露参考偏倚；m1 与只重比对图分支的差别在此更明显。
- 能支持的结论：三种被测配置中，混合改善了该定义下的参考偏倚，尤其 m1。
- 不能支持 / 混杂因素：不是所有位点接近 0.5 就都放对了位置；真值高置信区域限制了分析范围，长 indel 分箱样本数远少于 SNP。三种配置不能严格证明与平台、读长无关。

![图 4：按等位基因长度分组的 ALT 支持比例及位点数](images/a51cf6168b6dc17a71a71b27153dc664550488f98eab53f6ee59804498e8b648.jpg)

Methods 给出的准确分母是可归属的 REF 与 ALT 支持之和：$b=n_{ALT}/(n_{REF}+n_{ALT})$，而 Results 曾简写成所有覆盖 reads。一个位点 12 条 REF、8 条 ALT 时 $b=0.4$；即使另有 5 条无法归属 reads 覆盖该处，也不应在这个公式中把分母改成 25。有限深度下单个位点自然波动，因而要按大量位点观察总体偏移，不能把每一处偏离 0.5 都当作比对错误。

#### E6：运行收益究竟来自混合，还是来自软件优化

并行时，时间按关键路径算，内存按同时存活进程的总占用算。粗略表示为：

\[
T\approx\max(T_{linear+route},T_{personalize})+T_{graph}(r)+T_{integrate}+T_{I/O},
\qquad M_{peak}=\max_t\sum_{j\;active\;at\;t}M_j(t).
\]

$r$ 是路由比例。即使 $r$ 接近零，所有 reads 的线性比对和样本图构建仍在。原始图比对从全量 2.78 h 降到子集 1.15 h，比例约 41.4%，远高于总体平均约 15% 的 reads 占比；不能据此计算精确单条代价，因为这里路由比例的均值与 HG003 的单次性能测试不是同一个统计对象，但足以说明运行时间不是简单按 read 比例线性缩放。

CPU-h 不是墙钟小时乘请求线程数。例如 dcsmap-opt 的 58.2 CPU-h/2.17 h 约为 26.8 个平均忙碌核；等待、串行和 I/O 都会拉低占用。图 5 记录了 CPU 与内存，是这篇系统论文做得较完整的一点。

- 检验主张：工具性能优化没有造成可观察的准确率下降。
- 设置与对照：17 数据集 × 3 对 origin/opt 工作流 × SNP/indel 两类型，共 102 对 F1 比较。
- 关键结果：配对 t 检验 $P=0.4483$；opt 更高 40 次，origin 更高 42 次，相同 20 次（Results；S10、S11 转述）。
- 定性现象：F1 差值围绕零，图 2 中配对柱几乎重合。
- 能支持的结论：在已评测数据上未检测到一致方向的平均 F1 改变。
- 不能支持 / 混杂因素：不显著不等于等效；102 对结果共享样本和工作流，独立性有限。没有预设可接受误差界、差值置信区间或逐位点 discordance 分析，不能证明 BAM/VCF 完全相同。

## 5. Limitation

### 5.1 作者明确报告

**分歧不是正确性。** Discussion 明确说明线性与图结果不一致不保证图位置正确；该标签是现实数据缺少 read-level ground truth 时的代理。这不是笔记强加的批评，而是作者对方法前提的承认。

**复杂医学区域有召回损失。** 更全面的 HG002 v5.0q 中收益减小，CMRG 中全图略好。作者指出重复、复制或其他复杂区域的 reads 可能获得看似高置信的错误线性位置，因而未进入图分支，并提出多样训练、区域阈值、局部复杂度特征或对困难区域直接路由等可能补救。

**系统并非全链条无门槛开源。** Availability 给项目代码 BSD 2-Clause、Linux、C++、Java 1.8，但同时明确其属于商业 DCSTools，依赖套件组件，需要申请 trial。开源项目入口不意味着本文优化后整条链能仅靠公开代码无条件重建。这是作者报告的可获得性条件，不是对其许可证合法性的判断。

### 5.2 基于论文材料的解析推断

#### 最脆弱的假设：线性置信度足以决定是否值得看更丰富的参考

实际系统想知道的是：多花图比对的代价，是否能降低最终错误？但路由器只看到线性结果自报的配对关系、MAPQ、CIGAR 和质量。假如某个重复拷贝没有被线性参考充分表示，错误位置反而可能表现为唯一的高分候选，两个 mates 也可能一起落在同一错误拷贝，保持正常间距。此时 proper-pair 和 MQ 不只是信息不足，还会朝错误方向提供强信号。

这一假设失败的代价最大，因为后面的图参考再好也没有机会看到这条 read。m1 可以修局部 indel，却不能被视为全局替代位置搜索。CMRG 的 recall 下降提供了与此一致的证据，但缺少逐 read 真值，尚不能量化有多少失误确由这一原因产生。

另一个不对称是训练目标把两种不同状态都标为正：线性错/图对，与线性对/图错。只预测分歧，无法从目标函数中学到这两类的区别。用一个简化表就能看到问题：

| 线性真值状态 | 图真值状态 | 是否值得改用图 | 分歧标签可能是什么 |
| --- | --- | --- | --- |
| 对 | 对，且同位置 | 通常无须 | 0 |
| 错 | 对 | 值得 | 1 |
| 对 | 错 | 不值得 | 1 |
| 错 | 错，且同位置 | 仅重比对未必可救 | 0 |
| 错 | 错，且不同位置 | 未必可救 | 1 |

这解释了为何单纯再提高 AUROC 也可能无法改善变异检出。目标错位与分类能力不足是两个问题。

#### 最小复现实验：先验证分歧是否真的代表收益

不必复现商业优化或跑完整 30× 全基因组，先测试最关键的代理标签。

选择一个包含 indel 和近似重复拷贝的小型合成二倍体参考，例如两段各数十 kb 的同源序列及其独特侧翼。保留一套线性参考，把真实两条单倍型及相关复制路径放进小图。按已知来源模拟 PE150 reads，保持固定插入长度分布和错误模型；每条 read 的原始位置与等位基因是已知的。这是实验提议，本文没有做过该模拟。

用公开版 BWA-MEM2 的论文 fast 参数和公开版 vg 跑两条分支，并将图结果投影到同一坐标。若要尽量接近标签流程，再给图结果加公开 ABRA2。先不训练 XGBoost，直接统计上表各格：位置分歧中有多少是线性错/图对，有多少是线性对/图错；在线性 MQ60 且 proper-pair 的 reads 中，错放率多高。把位置正确与局部 indel 表示正确分开评分，并事先固定正确位置的容差。

若分歧集合主要是图能修复的错误，且线性高置信集合很少错放，就支持代理目标；若大量分歧是图把正确结果改错，或者高置信线性集合包含大量可被图纠正的错误，则直接反驳代理能可靠决定路由的假设。真实数据中也可做同样的对照，但没有逐 read 来源就只能间接判断，不能声称得到了位置真值。

完成这一最小检验后，才比较三个同预算选择器：仅 unmapped、proper-pair 加 MAPQ 简单规则、论文特征的分类器。固定图路由比例如 15%，比较选中集合的真实收益，而不是允许一个规则重比对更多 reads 后宣布更准。重复模拟种子并按独立区域分割训练/测试，可以避免把数百万高度相关 reads 当作同等数量的独立泛化证据。

#### 最强反例设计：让错误定位拥有所有正常信号

构造两个高同源拷贝 U 与 V。样本的 U 含有线性参考 U 缺失的插入，而参考 V 的局部序列恰好更像样本 U。将 read pair 的两端都放在两个拷贝共有的范围内，保持距离与方向正常；通过两端联合路径及侧翼连接，使图中真实 U 路径可获得更好的解释。扫描同源程度、插入大小和可辨识侧翼距离，专门寻找下面这个区间：BWA-MEM2 把 reads 高置信放到 V，图方法则利用正确路径将它们放回 U。

这里必须承认一个信息论边界：若两套位置对整对 reads 完全不可区分，图方法也无法凭空知道真实来源。反例需要保留足够区分信息，让全图能成功而路由器因线性特征正常不去尝试；不能把所有算法都做不到的情况拿来只批评 DCSMAP。

主结果不报告全基因组平均 F1，而报告这个预先定义区域内的 U 变异 recall、错放到 V 的 reads 数、MQ60/proper-pair 错误的漏路由率，以及两流程相同预算下的错误数。若全图恢复 U、混合持续错留 V，就直接击中方法的核心假设。再逐渐增加此类区域在测试集的比重，观察总体优势何时反转。这比随意寻找一张失败截图更有解释力。

#### Follow-up Research Idea：从预测分歧改成购买能减少位点错误的证据

**这是笔记提出的研究设想，不是本文已有工作，也没有完成全面新颖性检索。** 对 DCSMAP 的自然修补是加难区特征、调低阈值。更有实质差异的问题是：在固定计算预算下，应购买哪一组额外比对，才能减少最终基因型错误？决策单位可以是位点附近的一组相关 reads，而不是逐 read 的分歧。

驱动力有两个。分歧不包含改用图是否更好的方向；同一位点的多条 reads 又共同影响 DeepVariant 和 ABRA2，单条 read 的收益不独立。例如缺少最后两条 ALT 支持时，重比对它们可能改变 genotype；已有几十条一致支持时，再重比对一条几乎没有收益。目标应该反映这个差别。

相邻领域已经研究 **learning to defer**：预测器学习何时把决策交给另一个专家，并把专家的错误纳入目标。Mozannar 与 Sontag 在 ICML 2020 的工作将其连接到代价敏感学习，提供一致代理损失。因此仅把路由改名为 defer 不构成新意。可借鉴的是**对两条分支各自的错误和代价建模**，而不是只预测二者是否不同。[原始论文：Consistent Estimators for Learning to Defer to an Expert](https://proceedings.mlr.press/v119/mozannar20b.html)

这里的新增问题是位点级证据交互和比对的不确定性。令 $w$ 为一个局部窗口，$z_w\in\{0,1\}$ 表示是否为该窗口购买额外图计算，$C_w$ 为代价，$B$ 为总预算；$\widehat g(z)$ 是在所有路由决策后调用出的基因型，$g^*$ 是真值。可以提出目标：

\[
\min_z\ \mathbb E[L(\widehat g(z),g^*)]
\quad\text{subject to}\quad \sum_w z_w C_w\le B.
\]

这里 $L$ 可以对重要区域的 FN 给不同代价，但必须事先声明，不能看到结果后改权重。窗口的收益是同一输入在保留线性与追加图证据两种操作下的**最终损失差**，不再是 read 分歧。式子难的地方是 $\widehat g$ 依赖成组证据，窗口还有重叠；它不是把 read 级分类器换一个 loss 就能解决。

第一个实验可在有已知单倍型的小型重复区模拟集上，将每个窗口分别运行线性、图和混合证据三种方案，得到可监督的收益与成本。训练时使用某些单倍型/区域，测试时留出整个同源家族或整个人。比较固定预算下的简单 MQ 路由、分歧路由、收益路由及知道真值的 oracle。画出**计算秒数与 genotype 错误数**的曲线，并单独看困难区，而不是再报告一个很高的 AUROC。

若收益路由在同样约 15% 的图预算下明显缩小与 oracle 的差距，尤其救回 CMRG 类型 FN，才说明新目标有价值。若它只能学到 MAPQ 或错误率曲线与分歧路由相同，就应承认该 framing 在当前数据上没有带来独立收益。更进一步可研究何时应保留多个位置的概率证据而不是强行输出一个高 MAPQ 位置，但这需要改动下游证据接口，不能只靠 BAM 合并解决。

**研究定位的依据。** Nature Methods 的 Personalized pangenome references（2024）体现了以样本相关参考减少无关变异、服务实际基因组分析的路线；ICML 的上述 defer 工作强调路由目标与统计一致性。由这两个已发表案例推断，一个有分量的后续工作应同时给出明确的新决策目标和困难区域的真实收益，而不只是多一个分类特征。这里是从具体论文归纳研究取向，不是声称期刊或会议有某种统一录用规则。[Personalized pangenome references](https://www.nature.com/articles/s41592-024-02407-2)
